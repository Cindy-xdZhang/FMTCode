## 唯一候选与完整计算

候选名`p35_n0_k06_single_center`；不是c156，不使用ASAP相机或Raw旁路。

1. 每个primitive只确定一个中心。Task3/5保持原slot0。Task4-c按存储的播种坐标，在有效线中一次性选择距原播种中心最近者；CPU float64计算，严格相等时按存储顺序。原中心线保留时即选原中心。训练196,960束中918束的原中心线已被旧清洗剔除，使用最近有效线，不丢弃样本、不补积分、不改标签。
2. 其余全部有效线作为邻居：Task3/5六条；Task4-c9–26条。后续全过程不轮换中心、不构造每线一个中心的token。每束输出一个141维向量。Task4-c全部邻居策略是无回复时采用的已告知默认实现，不声称用户已明确选择。
3. 对全部有效点做整束质心平移、最大半径缩放（n0）；本轮使用旧数据的32点，不重采样。编码器也接受48点，输出宽度不变。傅里叶自变量为存储采样序号，不称物理Hz。
4. 保留前六个实数离散傅里叶频率（含直流）。中心相邻采样差向量的实部范数、虚部范数、夹角余弦和相邻频率归一化有向三重积，共23维；归一化中心坐标及单位切向的实/虚频谱，共72维；每个邻居相对唯一中心的差向量沿采样轴差分，再计算相同23维描述，分别逐维取算术均值和数值最大值，共46维。总计23+72+23+23=141。neighbor_scale=neighbor_weight=1；不加入kin、IVD估计或原始坐标旁路。
5. 与旧n0七线公式相同，几何与傅里叶中间计算统一float64后输出float32，减少弱信号的设备舍入差异；这不是旧float32实现的逐位复现。训练集逐特征均值/标准差归一化；std<1e-8置1，无signed-log和裁剪。
6. 完整网络只有141→256→128→64→2全连接层；三个隐藏层各LayerNorm、GELU、Dropout0.15，共78,530参数。输入必须[B,141]，禁止[B,L,141]。训练前递归检查无卷积，同时审查函数式计算无卷积。无可学习编码器、无Raw分支、无多中心后的学习池化。

72维方向分支保留坐标信息；不能宣称本配方对任意时变刚体观察者完全客观。

## 数据、预算与选择规则

三任务共同seed40：Task3十流场十次、Task5十流场十次、Task4-c合并Channel/TBL一次，共21次正式拟合。只核验上述一个候选；不比较候选、不自动调参。V100最多同时4卡，正式训练前CPU独立NumPy复算、GPU同批/跨批检查和每任务32个真实训练样本拟合检查；小拟合不是正式成绩。所有模型只保存在内存，不写权重。

Task3/5完整复用`config/mainExp_Task135_FMTv8_1.1.json`的数据路径、角色、原IVD95标签和样本行；保留Task5的18/6/9尺度划分及两个修复流场的原缓存。AdamW(lr0.001,wd0.0001)、batch512、最多100轮、patience20；训练类比例加权二元交叉熵，验证average precision选轮次，改进下限1e-4，无学习率调度；锁定轮次后验证F1最大值选阈值，再读取原test。原benchmark已在历史使用，不宣称全新独立确认集或严格物理时间隔离。

Task4-c使用最新`mainExp_Task4C_GTHeadCoverage_1.1`：196,960训练／3,000验证／11,320测试。科学源commit`c3952a7b8cafa10a50d73703da65c36279713368`，18文件及原数据审计哈希固定于`config/Verify_Task4C_P35GTHead_1.1.json`；读取该配置仅用于数据，绝不调用其多中心模型或训练。保持旧标签及文件，含新增1,320正类头部测试束。AdamW(lr0.001,wd0.0001)、batch128、普通交叉熵、gradient clip5、最多500轮、patience50；验证F1优先、average precision打破平局；验证交叉熵平台15轮后lr×0.5、最低1e-6；固定阈值0.5。共享GT实例的局部评估，不能称未见实例泛化。

每个拟合先写`selection.lock.json`再读取测试特征和标签。Task3/5分别报告十流场等权平均F1，Task4-c报告全部11,320束合并F1，并另列原10,000束/新增1,320束与两流场结果。三任务综合为三个任务F1等权平均；不得把20流场和一个Task4-c直接平均而稀释Task4-c权重。所有结果明确单种子，不能称已证明统一最佳。
