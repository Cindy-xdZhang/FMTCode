# Task6：直接学习几何编码与重建 5.1

版本`Verify_Task6_DirectNeural_5.1`。2026-09-11用户要求实现并部署：`geometry → 冻结FMT → 可训练编码器 → 低维token → 可训练解码器 → geometry`。只执行Task6，3.1/4.1代码、数据与结果保持冻结。

## 所检验的问题

4.1的固定编码通路包含解析逆变换与几何主成分投影，并在每次推理中存在。5.1的神经网络禁止调用逆傅里叶变换、累加还原轨迹、主成分分析（PCA）或用这些操作构造网络权重。PCA只作为独立的192维线性压缩基线，不参与网络初始化、损失或推理。完整16频FMT本身仍是可逆表示；本实验检验该输入表示能否改善学习得到的192维几何编码，不把它等同于频谱截断压缩，也不声称它是旧161维fmt_all。

## 数据与对照

沿用4.1九流场、256/1024/4096嵌套小训练集；1024为主设置。搜索子集/种子94110；最终94111/94112/94113，确保与4.1物理样本配对。全部标准化、网络训练与独立PCA只使用相应小训练集。12,000个validation、test和unseen_scale保持3.1/4.1原角色。测试集已使用过，属于既有benchmark，不是新的confirmation。沿用完整七线32时刻、18训练尺度/9未见尺度及Cylinder原时间范围[7.5,12]播种规则，不重新积分或缩短轨迹。

| 方法 | 输入 | 编码/解码 | 压缩维数 |
|---|---|---|---:|
| signed_fmt16_neural | 651个完整带符号复系数，保留七线身份 | 随机初始化、全部可训练的网络 | 192 |
| raw_neural_matched | 七线31个非初始点的651个坐标；已知初始21坐标不重复输入 | 与FMT完全相同架构、参数数量和训练配置 | 192 |
| raw_neural_selected | 同上 | 四候选中由相同validation规则独立选择；与matched相同则复用模型 | 192 |
| geometry_pca | 相同651个原始坐标 | 仅在小训练集拟合的PCA投影和还原，不含神经网络 | 192 |

不同Raw角色若配置相同，只训练和评估一次。PCA每个子集/种子只拟合一次。4.1含固定逆变换的结果只作为历史参照，不与本版混合求平均。

## 网络与数值约定

编码器为可训练线性投影加可训练多层感知机（MLP）修正，解码器结构相同。MLP隐藏宽度512，各3个两层残差块；潜变量192。两种输入维数均651，随机种子相同时初始可训练权重逐位相同。没有冻结的输入到潜变量或潜变量到输出矩阵，没有token/geometry绕过潜变量的路径。

输入使用train-only逐通道均值/标准差；输出只使用train-only逐坐标均值和一个全局标量尺度作数值标准化。这些统计量不依赖测试输入，不恢复每个输入的几何；所有输入相关的几何变化均通过学习的潜变量。初始七个种子是协议固定十字架。解码器最后投影/末层初始化为零，因此未训练预测是训练集平均轨迹。其余权重随机初始化，绝不使用PCA/SVD/解析逆变换预训练。

后验使用192个可训练对角对数方差，初值-18、裁剪[-24,0]，训练时采样、评估使用均值。几何损失为完整非初始坐标三维平方距离均值，除以该流场小训练集的全局位置方差尺度；这只是与坐标无关的正标量缩放，Raw/FMT相同。KL权重1e-5；结果仍用原物理定义RMSE/r，禁止改分母或按目标旋转/重排。

## 训练、选择及运行顺序

先做本地/远端结构测试，再对每流场最先取出的32个搜索训练primitive做两个无正则化小集拟合检查：4000更新、batch32、学习率1e-3余弦衰减。仅访问train，要求训练误差至少下降90%，并检查将潜变量设零后误差增加；失败则后续依赖停止，不通过改变测试集绕过。

正式搜索仅在1024样本、94110种子上进行，九流场、两臂、四候选，共72模型。每模型20,000更新、batch256、学习率余弦降至10%、梯度裁剪1；每1000更新检查全部validation，只选择正训练步最低误差。候选如下，Raw/FMT一一配对：

| 候选 | 初始学习率 | dropout | 权重衰减 |
|---|---:|---:|---:|
| c0 | 0.0003 | 0 | 0 |
| c1 | 0.0003 | 0.10 | 0.0001 |
| c2 | 0.0001 | 0.25 | 0.01 |
| c3 | 0.001 | 0.10 | 0.0001 |

按九流场等权validation均值选择一个FMT候选，统一应用于所有流场与样本量；Raw主对照使用相同候选，另保留独立validation最佳Raw。选择文件在最终训练之前冻结并记录SHA256。最终三个子集/种子重新从随机权重训练，每模型同样20,000更新和validation选择规则。若某模型选中validation RMSE/r>=3，保存失败并不访问其test；失败不能从汇总中删除。测试不参与任何选择。

评价包括同尺度test及unseen_scale，主指标为七线31时刻对应点三维RMSE/r，另列端点、中心、邻居及同时间点间距离。每流场三个种子平均，再九流场等权平均，报告全部样本量、逐流场和种子差值。保存预测，独立从预测复算标量；模型最优状态只在内存，不生成checkpoint。每个Ibex进程登记提交、版本、配置、commit、开始/结束、设备及状态。
