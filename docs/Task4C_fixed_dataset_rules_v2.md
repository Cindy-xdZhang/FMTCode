## 1. 样本定义 [用户]

一个样本本质上是三维空间中的一个**采样点**。从它出发沿涡量场积分得到的涡线（vortex line）是它的曲线。**不再产生任何邻居线条**：训练/测试的各个方法自己制定如何从一个采样点向周围查询别的样本点（曲线）的方式和数量，作为局部曲线簇。

## 2. 构造流程

**step1 候选区域 [用户]。** 对流场取满足 λ₂ 涡判据（λ₂ < 阈值；Channel −13.395，TBL −0.0272）且展向涡量脉动 oyf > 0 的区域，作为 head 头部候选区域。
[实现] λ₂、oyf 取原始 VTK 的 PointData，在任意位置按三线性插值判断；候选区域即 {x : λ₂(x) < 阈值 ∧ oyf(x) > 0}。候选格点按 26 连通分成连通分量（只用于第 3 节的归属）。

**step2 播种与积分 [用户]。** 在候选区域内产生 M 个初始点，再按 Poisson disk sampling 降采样成 N 个样本点，以保证分布均匀。每个样本沿涡量向量场 RK45 双向积分；单方向目标长度 Channel 0.07 / 0.10 / 0.13，TBL 3.5 / 5 / 6.5；步长用冻结值 Channel 0.001、TBL 0.025。每个样本的三种长度都要积分，即每个样本三条曲线。样本数量 Channel 50%、TBL 50%。
用户 2026-09-18 晚裁定的规模（第二次修正）：**初始点 M 总计 4,000,000、样本 N 总计 400,000，两流场各一半（每流场 M = 2,000,000，N = 200,000）**。

[实现]
- 初始点池：在含候选顶点的网格单元内按**物理体积**均匀随机撒点，只保留三线性插值仍满足 step1 的点，直到每流场凑足 M 个（固定种子）。因此初始点在候选区域内按物理体积均匀分布。
- Poisson disk 降采样：对初始点做固定种子的随机排列，按序贪心接受与所有已接受点距离 ≥ r 的点（dart throwing）；r 由二分法取到“恰好能接受 ≥ N 个点”的最大值，前 N 个接受点即样本。r 记入 `preparation.json`。
- 三条长度用**一次积分**得到：固定步长 RK45 下短曲线是长曲线的精确前缀，积分到最长长度（Channel 130 步、TBL 260 步/方向），再按步数截出各长度（Channel 70/100/130 步，TBL 140/200/260 步）。用户已确认此做法等价于三次独立积分。积分器沿用 GTHeadCoverage 1.1 的冻结设置（VTK vtkStreamTracer、RK45、初始＝最小＝最大步长＝ds、最大误差 1e-4·ds、传播守卫 0.001 步）。
- 曲线清洗：非有限值、去重后点数 ≤ 2、任一坐标轴跨度为 0 的曲线无效；半线实际弧长须在 [0.95L, 1.002L] 内。**[用户 2026-09-18 晚（二）] 如果半线因为离开流体边界（VTK 终止原因 OUT_OF_DOMAIN = 1）而达不到目标长度，该半线的弧长条件放宽到 [0.25L, 1.25L]**，曲线照常按弧长均匀重采样 32 点，并记 `boundary_relaxed`。[实现] 放宽只针对出域且步数不足该长度的半线；同一样本中未出域的半线仍用 [0.95L, 1.002L]。有效曲线按弧长均匀重采样 **32 点**（用户确认）。**三条曲线全部有效才保留该样本，无效样本删除、不补采**（用户确认），因此最终样本数 ≤ N。

**step3 归属 [用户]。** 所有播种点按所属 hairpin 实例分组：播种点落在某 hairpin 实例的 bounding box 内、或其头部候选区域归属该实例，则属于该实例；不属于任何实例的播种点划归**距离最近**的实例。**归属与标签是两件事**：归属只决定样本划给哪个实例（用于以实例为单元组织训练/测试集）；**标签来自该位置点查询 ground truth**。

[实现]
- 标签：播种点落在人工标注的 hairpin 网格单元（CellData `VortexIds`，编号 0 有效）内 → 1 并记该实例；否则 → 0。
- 归属按以下顺序取第一个成立者，记 `assignment_kind`：
  0 播种点在某实例标注单元内 → 该实例；
  1 播种点在某实例 GT 包围盒内 → 该实例（落入多个包围盒时取标注单元最近的实例）；
  2 播种点所在候选连通分量与某实例标注单元有格点重叠 → 重叠格点最多的实例；
  3 其余 → 标注单元最近的实例。

**step4 分折 [用户]。** 以 hairpin 实例为单元，把数据分成五份，训练集：测试集 = 4 : 1；后期做 cross validation 轮换测试折。

[实现] 每流场分别分折：GT 包围盒重叠的实例绑在一起（沿用 v1 的做法），按固定种子随机排列后，以“样本数最多的组先放、放入当前样本数最少的折”贪心平衡五折的样本数。每个样本记 `fold`（0–4）；v2 首版以第 0 折为测试、1–4 折为训练（`split`），轮换只需改读取时的测试折编号，**不重建数据**。不再有 v1 的验证集、距离规则、覆盖配额或未见组；各方法若需验证集，从训练折内部自行划出并如实标注。

## 3. 存储（每流场一个目录 `physical/<flow>/`）

- `seeds.npy` float64 [n, 3]：样本点物理坐标。
- `curves.npy` float32 [n, 3, 32, 3]：三种长度（短→长）的曲线，物理坐标、按弧长均匀 32 点，**不做归一化**（归一化属于读取方）。
- `metadata.npz`：`label`、`instance`、`assignment_kind`、`gt_owner`、`fold`、`split`（0 训练 / 1 测试）、`component`、`component_size`、`lambda2`、`oyf`（播种点插值）、`local_grid_scale`、`half_arc_lengths` [n,3,2]、`half_step_counts` [n,3,2]、`half_termination` [n,2]（VTK 终止原因）、`boundary_relaxed` [n,3]、`curve_bounds` [n,3,2,3]、`requested_half_length` [3]、`ds`、`poisson_radius`、`pool_index`（样本在初始点池随机排列中的序号）。
- `preparation.json`：候选区域统计、初始点池与 Poisson 参数、实例分折、逐实例样本数、清洗拒绝计数、文件哈希、代码身份。

## 4. 核验（audit-data）

从原始场重新计算并逐样本检查：播种点三线性 λ₂ < 阈值 ∧ oyf > 0；任意两样本距离 ≥ r；抽样重新积分并与保存曲线一致；三条曲线半线弧长与步数在界内、32 点、有限、无坐标轴退化；标签＝GT 单元归属；归属按第 2 节 step3 规则重算一致；折按实例划分且每实例只在一个折；Channel/TBL 目标各 100,000 且最终数 ≤ 目标。通过后 `data_audit.json` 内文件哈希即冻结哈希。

## 7. 实现细节补充（2026-09-18 晚，实现方）

- 样本所属的候选连通分量取**离播种点最近的候选格点**所在的分量（三线性候选点的所在单元不一定有同时满足两条件的顶点）。
- Poisson disk 半径二分从一个几何估计值起步（候选单元体积×接受率 / N 的立方根）；二分路径决定最终半径的最后一位有效数字，半径与起点都记入 `preparation.json`，核验以记录的半径复现选择并检查其最大性（放大 10 倍容差后接受数不足 N）。
- 初始点池按 2,000,000 点一批做拒绝采样，直到凑足 M；真实接受率记入 `pool.acceptance`。
