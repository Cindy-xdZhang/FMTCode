## 2. 跟随中心的相机

七条轨线是同一组物质粒子在共同物理时刻的采样，中心粒子记为 `c(t)=x_0(t)`；`r_i=x_i−c` 是客观相对位置向量。定义

```text
u(x,t) = c_dot(t) + Omega(t) [x−c(t)],
Omega z = omega × z,    Omega^T = −Omega.
```

这固定的是 `u(c,t)=c_dot(t)`。若写成全局形式 `u=b+Omega x`，则 `b=c_dot−Omega c`，全局截距 b 仍随所求旋转变化，不能预先独立固定成 c_dot。

令 R 把相机坐标旋转到输入坐标，解

```text
R_dot = Omega R,       R(t_0)=I,
y_i(t) = R(t)^T [x_i(t)−c(t)],
y_dot_i = R(t)^T [x_dot_i−c_dot−Omega r_i].
```

中心始终为零。这里采用以中心为原点的坐标；文档采用的 `c(t_0)` 回移只是时间不变的平移。R 必须随时间积分；只相减 `v−u` 还不是观察坐标下的轨线。对已知完整粒子轨线逐时刻应用上述变换，是精确链式法则允许的实现；若有原始速度场，直接积分 `R^T[v(c+Ry,t)−u(c+Ry,t)]` 可作为独立检查。

## 3. 两个目标不能互换

### A. 粒子簇尽量静止

对用户所述“primitive 在相机下几乎不变”，可定义

```text
E_motion(t) = sum_i w_i ||r_dot_i − omega × r_i||^2.
```

权重固定且不依赖观察者。每时刻三个未知数；直接堆叠 `−sqrt(w_i)[r_i]×` 并用奇异值分解求线性最小二乘。其正规方程是

```text
H omega = g,
H = sum_i w_i (||r_i||^2 I − r_i r_i^T),
g = sum_i w_i r_i × r_dot_i.
```

这最小化相机内粒子速度平方，也最小化其时间积分（固定平移、无角速度平滑惩罚）。它不等于最小化相对于初始形状的累计位置误差。剩余 `y_dot` 是所选局部刚体拟合意义下的非刚体运动；不能未经额外论证称为唯一的材料本征应变张量。

### B. 文档中的速度场尽量稳态

文档最小化的是固定观察位置处的速度场时间导数，lab 表达为

```text
d = partial_t v − partial_t u + (grad v)u − (grad u)v.
E_field = sum_i w_i ||d(x_i,t)||^2.
```

代入中心约束后，令 J=grad v，有

```text
d = (partial_t v − c_ddot + J c_dot)
    + ([v−c_dot]× − J[r]×) omega + [r]× omega_dot.
```

若保留这个目标，需要原场的空间梯度、Eulerian 时间导数与中心加速度，并明确处理 omega_dot 与 omega 的时间相容性。逐时刻另外拟合 omega_dot 后丢弃，并不能保证所得相机轨迹达到所报告的导数目标。低阶代码直接省略 partial_t u，属于另一个近似。

反例：稳态刚体旋转场 `v=omega_0×x` 的 lab 相机已经满足 `E_field=0`，粒子却仍在转；共转相机也可满足 `E_field=0`。因此“速度场稳态”既不推出“粒子静止”，也不总能唯一选出相机。需要先明确本 demo 的目标，不能用 A 的实现冒充 B。

## 4. 目标 A 的客观性条件与跨时刻特征

对时变刚体换坐标 `x*=Q(t)x+d(t)`，同一物质粒子满足

```text
r*=Q r,
r_dot*=Q r_dot + Q_dot r,
Omega*=Q Omega Q^T + Q_dot Q^T.
```

最后一式是相机角速度的变换规律，包含观察者自转项，不是普通客观向量规律。由此最小二乘残差满足 `e*=Qe`。若 H 可逆，最优解唯一并满足该规律。两次独立求解都取初始 R=I 时，

```text
R*(t)=Q(t) R(t) Q(t_0)^T,
y_i*(t)=Q(t_0)y_i(t).
```

所以输出轨线只差一个**时间不变**的初始旋转；跨时刻的距离 `||y_i(t_b)−y_j(t_a)||`、点积和夹角是数值不变的标量。原始 y 的三个分量不是数值不变特征。直接把这些分量交给任意网络也不能自动获得客观输出。

H 可逆要求相对位置不全共线（非退化的平面点集也足够）。共线时沿该线的旋转无法识别，不能默默用最小范数解就声称得到了唯一客观相机。实际数据还需要保留真实同步物理时间；每条线各自按弧长重采样后，相同索引通常不是同一时刻。时间差分与旋转积分带来有限精度误差，须另行检查，不能把连续证明当成离散机器精度保证。

## 5. 文档中额外需要区分的表述

- 一般非 Killing 场在某一点构造刚体场时，应取梯度的反对称部分；直接使用完整梯度通常不再是 Killing 场。原场本来是 Killing 场时才无需这一步。
- 正式英文文档 §6.1 的初始变换恒等只保证位置坐标相同；观察速度仍为 `v−u`，一般不等于 lab 速度。
- 是否存在三维实现、内存是否不可承受、低阶与高阶结果是否接近，不能仅由最小二乘公式推出。本文只使用已核对的公式与代码事实。
