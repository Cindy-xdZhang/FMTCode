## 全部线段着色

默认选择“全部线段：按拉直影响大小着色”。每条32点曲线分成点0–8、8–16、16–24、24–31四段，端点包含在两侧片段中，但31条边恰好各显示一次。原实验有七个重叠窗口，这四段均为其中真实测过的完整窗口；没有插值、平均重叠窗口或伪造逐点贡献。剩余的4–12、12–20、20–28窗口仍可在“选一段”模式查看。

模型分数 `m = logit(Hairpin) − logit(Non-hairpin)`；每段使用原始 `Δ = m(原束) − m(只拉直该段后的束)`。

- 红色：Δ为正，原形状相对于拉直形状更支持Hairpin。
- 蓝色：Δ为负，保留原形状反而降低Hairpin分数。
- 灰色：Δ接近零。颜色越深，影响的绝对值越大。

当前显示的全部线束共用对称色标，范围取这些片段的最大绝对Δ，不截断。单束、画廊和物理位置模式使用相同规则；切换线束或翻页后重新确定色标，界面显示范围。不同页面的深浅不能脱离色标直接比较。每段内部同色；绘图数据在段间断开，避免跨段颜色插值。

悬停显示线号、点区间、Δ和拉直前后概率。点击曲线、热图、表格或下拉选项查看该段；全段模式保持全线着色。热图为每线四列，和曲线使用同一色标；片段表包含当前束所有四段，不只列最强的片段。紫色替代直线仍默认隐藏。

每个分数描述一次整段拉直实验，不是某点的独立贡献，也不能相加成总贡献。全束归一化和重新编码仍由冻结的原计算决定；本次没有重新训练或重新做干预。
