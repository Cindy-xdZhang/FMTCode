# Task6：带符号傅里叶编码与稳定VAE重建 3.1

实验版本`mainExp_Task6_Reconstruction_3.1`。用户要求从第一性原理修复高重建误差，目标是各流场测试RMSE/r低于1。本版保留七条32点轨迹、固定初始中心与半径归一化、原物理时间与尺度定义。旧2.1源码和13以上的历史结果不覆盖。

## 方法与版本区别

| 项目 | 冻结2.1 | 修复3.1 |
|---|---|---|
| FMT | `fmt_all`，161维，六频Gram不变量/模长与邻居排序 | `signed_fmt10`，399维，十频复系数实部、虚部，保留三维方向、相位和七线身份 |
| 核心代码 | `FMT_Utils/DFT_FMT_3D.py` | `FMT_Utils/Task6Recovery_3D.py::signed_fmt` |
| 潜变量 | 64 | 192 |
| 初始化 | 随机全连接网络 | 只在本流场train几何拟合主成分基底，先得到可解释的低维几何近似，再训练编码/解码残差网络和后验方差 |
| 每流场train数量 | 60,000 | 240,000，新固定采样种子 |
| 模型选择 | 最后120epoch | 固定训练32epoch，在正更新步的validation探针中选择误差最低者；无test选择 |

**新编码不是旧161维FMT**，不能将它的指标记到`fmt_all`名下。原六频分类配方保持冻结，2.1仅作历史参照；3.1的主比较为新signed-FMT-VAE与同结构Raw-VAE，使用相同新数据、潜变量、训练曝光、KL和解码器。该比较回答新编码是否能支持完整几何重建，不自动证明它优于Raw。

对半径归一化的几何`x_i(t)`，先构造中心线增量和六邻居相对中心的增量：`Δx_0(t)`、`Δ[x_i(t)-x_0(t)]`。每条线有31个时间间隔，做离散傅里叶变换并保留k=0..9，共10频；零频虚部恒为0不存，其余复系数全部带符号保留，共`7×(10+9)×3=399`个数。积分的初始状态是协议固定的单位七线十字架。保留全部16个实信号频率可逐数值重建全部31增量；十频为实际有截断的压缩方案。

## 网络数据流与初始化

`geometry → 冻结signed_fmt10 → 可训练VAE编码器 → 192维潜变量 → 可训练VAE解码器 → 同一七线geometry`

初始线性编码器/解码器由train数据的主成分分析拟合；signed-FMT输入通过其固定线性逆变换矩阵映射到主成分空间，Raw输入使用相同主成分空间。线性路径及几何均值作为拟合后冻结的初始化缓冲区；隐藏宽度512、3个双全连接残差块的编码/解码网络可训练。编码器残差乘0.01控制初始化扰动，解码器残差直接预测几何修正；残差末层从0初始化。192维后验对角方差可训练，初始log variance=-18，裁剪[-24,0]。

所有输出自由度仍经过192维潜变量；**解码器只接收潜变量，没有geometry、token或逆变换结果绕过潜变量的输出支路**。初始七个种子坐标是所有样本共同的协议常量，解码时固定；后续31个时刻全部由潜变量重建。初始线性重建成绩单独记录，不能把初始化已经达到的误差全部归功于后续神经网络优化。

## 数据与训练冻结

数值配置：`config/mainExp_Task6_Reconstruction_3.1.json`。9个原流场；每流场240,000 train、12,000 validation、12,000同尺度test、12,000未见尺度test。沿用2.1的18个训练尺度与9个未见尺度、最大13帧完整窗口、空间步幅ceil(size/96)和初始半径单位。先按源帧分块，完整积分及插值源帧不跨train/validation/test。新数据种子2026091031；模型种子93110/93111/93112。

普通流场播种10%–80%，Cylinder按原[0,15]播种7.5–12。所有源窗口保持完整；不删除高误差样本，不缩短轨迹，不改变r或误差单位，不做目标辅助旋转/排序。

先从train随机固定512个primitive，运行8,000次更新的小集拟合；其“验证”是同一小集，只作拟合诊断。主模型重新用全部train拟合初始化，并重新初始化残差网络，训练32epoch，每批512，约15,008更新、768万primitive曝光。AdamW学习率1e-4，余弦降至10%，weight decay=0，梯度范数上限1；几何损失仍为七线×32时刻三维平方距离均值，KL按样本/潜变量维度平均，beta全程1e-5。

每500更新记录固定train探针与全部validation误差；只从step>0的探针选择最低validation误差模型，不允许直接拿step0初始化作为“神经网络训练完成”结果。模型/最优状态只在内存保存。validation误差须低于0.8才打开test文件，否则保存失败信息并停止测试，继续排查。

## 证据与评价边界

频率与潜变量容量只参考`Verify_Task6_ReconstructionAudit_2.2`的train/validation诊断：十频的独立逆变换验证误差目标上界0.25，192维线性几何验证误差目标上界0.1，留出距离测试1的余量。没有使用本版test选参数。独立逆变换和PCA仅作诊断/初始化，不冒充VAE评测。

主测试为新随机种子的完整未见primitive；另列未见尺度。源时间块与2.1相同，所以不是全新的时间确认。此外，对2.1已使用的固定test再评估，命名`legacy_test`，用于检查是否确实把原来产生高误差的**同一批轨迹、同一单位**重建好；它明确是历史benchmark，不用于模型选择。

每流场每个种子的误差都报告；不能仅靠宏平均宣布达到目标。最终审计从保存的geometry预测独立复算全部指标，并检查正训练步、正KL、数据/config/commit、无模型文件。任务只限Task6。方法结论写入`docs/experiment_log.md`，所有提交/开始/结束/实际设备写入`docs/ibex_run_registry.md`。
