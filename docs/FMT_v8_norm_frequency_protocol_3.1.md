## 20组候选

统一的是每个任务调用的公式和运算阶段，不是把不同任务的训练数据混合估计一套数值统计量。

|配方|几何归一化|傅里叶及池化后的特征归一化|
|---|---|---|
|n0|有效点质心、最大半径|训练集逐特征均值/标准差|
|n1|有效点质心、最大半径|signed log1p、训练集逐特征均值/标准差、截断到[-8,8]|
|n2|有效点质心、均方根半径|训练集逐特征均值/标准差|
|n3|有效点质心、均方根半径|signed log1p、训练集逐特征均值/标准差、截断到[-8,8]|

每套配方分别取 K=2、4、6、10、16，共4×5=20组。候选名称为 `n0_k02` 等。K包含零频率，保留 k=0,...,K-1。中心/邻居差分有31个采样点，共16个独立实数输入DFT频率；方向分支32点有17个，本次使用共同上限16，且三个分支取相同K。

|K|中心 4K−1|方向 12K|邻居均值 4K−1|邻居最大值 4K−1|总维数 24K−3|Task4-c参数|
|---:|---:|---:|---:|---:|---:|---:|
|2|7|24|7|7|45|64,450|
|4|15|48|15|15|93|70,594|
|6|23|72|23|23|141|76,738|
|10|39|120|39|39|237|89,026|
|16|63|192|63|63|381|107,458|

每个输入样本有效坐标集合为 X，先算 μ=mean(X)，再算 r=max‖X−μ‖ 或 r=sqrt(mean‖X−μ‖²)，最后 x=(X−μ)/r。质心和尺度使用float64，输出float32。Task3/5的一个样本为七线×32点；Task4-c为原束中10–27条有效线×32点。Task4-c保留整束相对几何，不对每条局部七线重新取质心/尺度。补零线不参与统计，重新归一化后仍为零。Task4-c的物理缓存已做过整束质心/最大半径归一化；在该缓存上重新计算公共公式，在数值精度内等同于对物理坐标执行同一公式。

中心步进序列为相邻点差；邻居序列为“邻居减中心”的相邻采样差。每个频率计算实部范数、虚部范数及其夹角余弦，另保留相邻频率的归一化有向三重积，合计4K−1维。六个邻居对每个特征分别排序，再分别计算均值与数值最大值，保持p35定义；不取绝对值最大值。所有新候选的邻居差分倍率=1、邻居特征权重=1，与任务无关。夹角165维、速度梯度、curl/IVD估计均不加入输入。

方向分支对“坐标xyz、单位切向xyz”六通道计算DFT，保留实部/虚部，共12K维。中心/邻居DFT沿用原默认缩放，方向DFT沿用原正交缩放，三个任务使用同一约定。本次“统一归一化”不修改DFT内部原有两种分支缩放约定。

特征归一化在上述拼接之后执行。signed log1p 定义为 sign(v)log(1+|v|)。均值、总体标准差只由各模型训练集中的有效特征向量估计，float64计算；标准差<1e-8统一替换为1。随后输出float32，n1/n3才截断到[-8,8]。评估数据只应用训练统计量。有效线标记单独添加，不参与归一化、不作为特征进入首个线性层。

原p35/h0保留之前分任务不同的几何/特征处理，因此新K=6候选也不等同于原p35；只能根据20组实测判断公共配方是否有利。方法级结论只写入 `docs/experiment_log.md`。

## 数据、网络与选择

- Task3、Task5：原10个流场；原IVD p95标签、采样时段和尺度划分不变，Cylinder原模拟时间下限7.5不变。种子40，每个任务先对10流场F1取算术平均。
- Task4-c：原4.14物理缓存，27,000训练、3,000验证；Channel和TBL合并训练/评价，种子96611。最近六邻居由原种子坐标计算，有效线数和样本标签不变。F1使用固定阈值0.5。
- Task3/5：Raw分支输入、原训练归一化和h0训练不变；每个任务/流场只拟合一次共享Raw和Raw-wide。Raw-wide只用于原冻结选择规则。FMT新特征补零至433维，冻结Raw加残差模型总参数142,914，其中训练残差52,993。FMT特征自有归一化不再被原训练器第二次标准化。
- Task4-c：逐线 `D→128→128`，有效线均值/最大值拼接256，分类头 `256→128→64→2`；LayerNorm、GELU和dropout0.15沿用h0。参数=58,690+128D，随K变化并报告。原AdamW学习率0.001、weight decay0.0001、batch128、最多500epoch、patience50和调度器保持。
- Task3/5：原h0 AdamW、学习率0.001、weight decay0.0001、batch512、最多100epoch、patience20保持；Task3原验证融合系数搜索、Task5系数1及各自原epoch/阈值规则保持。不额外搜索学习率、激活或正则化。
- 总分为 `(Task3十流场均值 + Task5十流场均值 + Task4-c合并F1)/3`，并列时先选维数较少、再按配置ID排序。20组全部报告，原p35单列；只有一套共同配方获选。
