# Task6 重建失败排查与修复 2.2

2026-09-10，用户要求从数据、积分、编码、网络和训练重新检查，验收目标为各流场测试位置RMSE/r低于1；超过3按工程失败处理，必须定位并修复，不用其作为停止工作的理由。旧2.1代码、缓存和结论保留，任何新配方明确另起版本。

## 阶段一：Verify_Task6_ReconstructionAudit_2.2

代码 `experiments/Verify_Task6_ReconstructionAudit_2_2.py`，配置 `config/Verify_Task6_ReconstructionAudit_2.2.json`。只读旧数据的train与validation，不读test/unseen_scale。九流场分别执行：

1. 从缓存的原播种位置、物理时间和完整积分参数回放4个固定样本，比较缓存；用半步长RK4检查积分收敛，再用SciPy独立四维插值与DOP853高阶自适应积分交叉验证。记录所有差异，不能先假定有错误或先假定无错误。
2. 直接公式复算位置RMSE/r；检查原FMT重新计算与缓存一致。报告静止初始簇、训练集均值簇、随机训练簇在validation上的误差，提供同单位参照，不靠“随机输出”的未定义分布解释结果。
3. 对保留复系数正负号、相位和粒子身份的傅里叶编码，分别保留6/10/16频率做确定性逆变换，测量编码截断误差。该操作只用于诊断，不冒充神经网络预测。
4. 用训练几何拟合主成分分析（Principal Component Analysis，PCA：用训练协方差的主要方向构造线性低维表示），检查64/128/192/256/384维的train/validation重建误差，评估潜变量容量与初始化所需尺度。

该阶段不改动冻结`fmt_all`，也不把signed Fourier新版本改名成旧161维FMT。发现的问题、没有发现的问题和证据分别写入`docs/experiment_log.md`。

## 阶段二：修复与验证

依据阶段一train/validation证据建立新运行配置，再确定网络及数据构建修改。保持七条线、32点、原初始半径单位、完整目标区间和时间块隔离；不通过缩短轨迹、改变误差单位、目标辅助旋转/重排或筛除大误差样本来达到阈值。VAE必须保留正KL权重，解码器只能接收潜变量，不能把原几何或逆变换结果绕过潜变量直接接到输出。

若调整FMT编码，必须明确标注新旧token信息、维数和代码路径；保留原FMT与同结构Raw的参照，不把新编码的成绩记入旧FMT。可增加数据量、潜变量和训练预算，可用train拟合的线性初始化和validation选择epoch，但必须在新test运行前冻结选择规则。

旧test已被查看，只作历史benchmark。新的primitive采样使用新的冻结随机种子；即使在相同源时间块另采样，也必须承认源时段并非全新，不能称为独立时间确认。模型结构、训练预算和超参数仅用train/validation选择。九流场逐项报告是否低于1，不能只用宏平均掩盖未达标流场。每个Ibex进程登记，模型不长期落盘。
