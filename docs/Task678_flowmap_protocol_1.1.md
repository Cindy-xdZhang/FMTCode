## 任务与实现范围

| 任务 | 输入 | 目标 | 主要问题 |
|---|---|---|---|
| Task6：局部流映射查询 | 可见 primitive 的特征 token、新粒子的初始局部位置和查询时间 | 同一时间区间内，未输入粒子的完整轨迹 | 一个 token 保留了多少可供查询的局部材料运动信息 |
| Task7：遮挡区域补全 | 隐藏区域外六个可见 primitive 的 tokens、相对初始位置和查询时间 | 隐藏区域中粒子的完整轨迹 | 多个 token 能否被相同上下文网络用来恢复缺失区域 |
| Task8：短流映射组合 | 两段已知短流映射各自的 tokens、起始位置和时间 | 组合区间的真实长轨迹 | 用第一段预测的到达位置查询第二段，能否正确组合运动 |

目标全部来自原速度场的数值积分，不使用 IVD、涡类别或 hairpin 人工标签。FMT（Fourier Map Tokenizer）编码器保持原实现；后处理主成分分析、变分自编码器和查询解码器仍需训练，不能把完整系统称为无训练参数。token 当前为连续特征，不引入离散词表。

Task8 1.1 使用 **Task6 训练的同一逐段查询解码器** 实际组合两段映射，不另训一个直接预测长轨线的网络。第二段的支持 primitive 中心是第一段可见中心轨线的终点，半径只从第一段可见邻居的末端范围确定，独立播种第二段支持及训练查询粒子；不使用目标粒子的真实到达点播种支持。组合查询使用模型自己的第一段预测终点，不能偷换成真值终点。第二段输入及其初始位置属于已知观测，因此本任务不宣称预测未知未来。当前评估两段及段内误差；更多段数组合需要新版本，不假称已经验证任意段数。

## 数据与隔离

当前覆盖九个具有时间序列来源的 3D 条目：Re160、Re640、Re6400、Tangaroa、两个 DeltaWing 来源、F22、Boeing、SmokeBuoyancy。已有单时刻 Channel VTK 不进入本批非定常主表。每个实际读取窗口还检查速度随时间发生变化；不通过的来源明确失败，不转换成相机运动伪造非定常数据。

沿真实时间坐标选择八个互不共享插值帧的九帧窗口，前四个训练，中间两个验证，最后两个测试。稀疏导出文件必须遵循其已导出帧清单；Re6400 只允许已有导出的 75–149 帧。缺帧不能填零用于积分。Cylinder 初始时间 t≥7.5。选择仅依赖数据可用性和时间，不根据新任务性能更换窗口。当前是每流场独立训练、跨时间评估，不是跨流场泛化；另报 physical-family 等权汇总，两个 DeltaWing 来源不当成两个独立物理 family。

每个窗口包含两个各四个源帧间隔的短时段，每段 62 个 RK4 步。可见轨线每隔一步采样，共 32 点；独立查询轨线保留全部 63 点；组合真值保留 125 点。因此可明确区分输入采样时刻及采样间查询。积分时对 RK4 中间位置也检查边界，所有特征方法共用预先确定的完整有效集合。

每个窗口从每轴至多 8 点的初始网格按数据种子选择至多 128 个 primitive 区域，最少需保留 24 个完整区域。各轴网格数仅按物理域宽度确定，必要时减少薄轴上的点数，保证不同区域中心间隔大于 10r；在读取性能前的来源检查中，Re160/Re640 薄轴需要降为 3 点，不能机械使用 8×8×8 造成区域重叠。实际网格形状逐窗口记录。基础半径 r 为读取网格最小间距的 0.5 倍。每个区域将基准八角点（各坐标 ±0.22r）按独立随机刚体旋转和 0.8–1.1 倍缩放生成查询种子，始终位于 cross 凸包内，不与可见材料点重复；随机数只由数据种子、窗口及区域编号确定，不读取速度或标签。训练/测试及两段各自采用不同的查询位置，避免只学八个固定位置。体积指标使用其中 0、1、2、4 四点组成的四面体。

原七线 cross 和旧 largeNeighbor 的 24 邻居球壳的并集共 31 条材料轨线，只为统一生成和存储。方法仍按原定义读取七条或二十五条：`largeNeighbor` 不改成 31 邻居方法。Task7 六个可见中心位于隐藏中心 xyz±3r 处，最外壳 2r；检查可见输入与八个隐藏目标播种点的距离大于 r。Task7 输入没有隐藏中心 primitive；其 IVD 估计的同时间均值只使用可见上下文集合。源时间窗口先拆分，再生成各任务数据。

第二段半径为 max(r, 第一段可见 cross 末端最大中心距×1.25)。组合目标的真实到达点须落在第二段 cross 凸包内；这一条件只定义共同的数据覆盖范围，不用于选方法或超参数，排除数必须记录。模型预测落到覆盖区之外时仍计误差，不能按某方法预测筛选测试样本。

## 特征、网络与预算

| 方案名称 | 输入/描述 |
|---|---|
| raw_pca7 / raw_pca25 | 原七线 / 二十五线位置序列，按初始中心和半径表达，再用训练集 PCA 压缩 |
| raw_vae7 | 七线原序列，经相同预处理，用变分自编码器学习潜变量；采用确定性均值作为 token |
| fmt_all | 原 161 维 Fourier 几何编码；包含中心时间差分，保持冻结默认参数 |
| fmt_all_kin4 | 原 fmt_all 与四频运动学块的既有组合 |
| fmt_all_v2 | 六邻居同时间 Gram 标量序列的客观 Fourier 编码 |
| largeNeighbor | 三层、24 邻居的同时间 Gram 标量 Fourier 编码 |
| aivd1w3_dft | 冻结短窗口 IVD 估计，输出一维；按真实同时间可见支持集合估计均值 |
| differential_geometry | 七条轨线全时段的曲率、挠率序列，加长度及速度统计；PCA 压缩，不使用真实速度梯度或标签 |
| coordinate_fourier | 七线相对初始中心坐标序列的实数 Fourier 系数，保留六个频率，含相位信息 |
| center_pca | 只保留中心轨线的诊断对照 |
| coordinates_only | 无流动 token，仅查询坐标、时间和公共尺度信息的诊断对照 |

神经比较采用 32/64 维 token 宽度，随机种子 9100/9101/9102。各确定性描述符只在训练支持上拟合标准化/PCA，低维描述符补零；补零不能算作保存了额外信息。`raw_vae7` 隐藏层 512/256、3000 次更新、KL 权重 1e-6、学习率 3e-4。查询网络隐藏宽度 128、2000 次固定更新、学习率 1e-3；不依据验证或测试择优 epoch。Task7 使用共享逐 token 编码与均值聚合，再用相同条件查询头。每个任务/宽度下，各方法的查询网络参数量相同；VAE 额外训练开销和参数单独报告。

初始局部查询位置、归一化时间、半径及时间跨度为各方法共同输入。真实全中心轨线不能额外旁路输入神经解码器。初始位置用于恢复实验室坐标，不作为流场身份输入。坐标输出强制在初始时刻等于已知查询播种位置。Task8 第二段支持的初始位置是其合法可见输入，明确它提供的信息，不与“只有第一段观测”的预测混为一谈。

另设不训练的原始七线局部仿射插值。Task7 对六个外部 primitive 的局部仿射查询做距离加权，Task8 逐段执行该插值再组合。其真实存储量为原始轨线，不能假称与 32/64 维 token 等预算；在字节数—误差表里如实列出。各特征最终有效维度、存储字节、公共位置/尺度字节、PCA/归一化状态大小、网络大小及运行设备均记录。

## 评估与记录

主指标为按初始半径归一化的对应粒子位置均方根误差；同时记录末端、后半段、输入采样间时刻的误差，以及逐时刻曲线。初始时刻是已给定位置，不纳入主要平均。另报同时间粒子间距离误差、去质心后的形状误差和四面体体积误差。完整输运与相对几何分别解释，不能只凭坐标误差优势声称更客观。
