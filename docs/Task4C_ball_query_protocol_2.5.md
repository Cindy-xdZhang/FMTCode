2026-09-19 用户明确要求立即实现、同步并部署 Ibex 并行比较。本条授权取代此前只更新分布、不恢复训练的状态。固定 **Channel h=0.003909492、TBL h=0.117239990**；h为三个方向“范围/(格点数−1)”所得平均间距的最小值，使用用户确认的舍入常数。原始范围与分辨率见 `docs/Task4C_ball_query_counts_2.4.md`。

## 冻结任务与邻居规则

沿用 v2 r3，审计SHA-256 `e5aaa4fb8a8e01882c461da5916b3bb96883e2787b231b018b512d7e30d3a2a8`；Channel189416、TBL198413个播种点，各三种长度。训练826005、验证91779、测试245703行；测试折0，训练折内固定10%验证。数据、标签、划分与归一化不变。

初始物理半径 Channel **0.011728476**、TBL **0.351719970**。在同流场全部播种点中查球，排除中心，不使用标签、实例或折来选邻居；沿用此前跨折几何可见的定义。目标k分别6、16：不足时独立扩至第k个其他点的距离；等于k则全取；多于k则以原中心开始，在完整球内做最远点采样（farthest point sampling，FPS），不截断成最近64点。距离并列按样本编号。没有人为最大半径；因此稀疏位置可能扩至较远处，不声称保证同一hairpin。

每行固定原播种点为中心，同一行的全部邻居使用与中心相同目标长度；每个k下五个模型共用相同邻居表。6与16的扩球独立，不能一律用16邻居的前6个代替6邻居。

## 候选、预算与评价

**唯一正式训练种子96611，总共十次拟合，不增加种子、不搜索半径、架构或超参数。** 沿用原训练预算：batch128，AdamW学习率0.001/权重衰减0.0001，dropout0.15，最多500轮，验证无提升50轮早停。仅按验证F1选轮，平均精度用于打破平局；测试阈值0.5，选轮锁定后才读取测试数据。单种子不报告标准差，不冒充多种子结果。

## 实现与预检

- `FMT_Utils/Task4C_BallQuery_2_5.py` 复用2.2的球边界/扩球规则；仅把FPS循环用Numba编译，不启用fastmath。与原NumPy实现逐数组对比，覆盖稀疏扩球、稠密球（超过64候选）、边界和距离并列。
- `experiments/Task4C_BallQuery_2_5.py` 复用冻结FMT2.1训练器和2.2数据接口。预检实际曲线、跨batch特征一致、网络参数与完整无卷积结构、小样本拟合；预检分数仅为工程检查。
- `experiments/Task4C_BallQueryBaselines_2_5.py` 从共享邻居表分别导出7/17条有效曲线，仍用旧27槽格式并屏蔽其余槽。复用已部署的 `Task4C_FixedDatasetBaselines_2_1.py` 导出/元数据/复算逻辑及各家族冻结网络与训练循环；原驱动逐字保留。其LF源码SHA-256与Ibex的725c100b版本相同：`1a45c01c743a0f1ec14e06a20715f15104493802321a4801e999f01af49e886d`。
- Conv3D缓存仅生成16³体素，省略原导出器未被Conv3D读取的旋转中心FMT缓存；体素函数、稀疏格式、float16缓存和网络输入与原实现一致。预检真实训练束的稀疏/稠密逐值往返、独立体素参考、batch128反向、显存与吞吐；其余基线复用原预检及真实束pilot。
- `tests/test_task4c_ball_query_2_5.py` 验证FPS加速等价、k6/k16导出选中编号/长度/标签/有效槽、十次单种子任务范围；另运行2.2邻居及2.1数据接口测试。
