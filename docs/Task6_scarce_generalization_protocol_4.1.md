# Task6 小训练集与正则化验证 4.1

实验`Verify_Task6_ScarceGeneralization_4.1`，2026-09-10根据用户要求新增。研究问题：真正减少可用训练primitive后，冻结傅里叶编码与正则化能否改善七线几何重建的测试误差？3.1源代码、24万训练样本结果和Raw对照保持冻结。本轮仅Task6。

## 数据与核心比较

沿用3.1全部九个流场、完整七线32时刻geometry、源时间块和尺度划分。每流场训练数量固定256/1024/4096，**1024为预注册主比较**，其余为样本量敏感性。每个随机种子先随机排列原train索引，再取嵌套前缀，抽样与标签、几何、误差无关。两臂共享相同索引。标准化、主成分分析初始化和网络训练均只读这些小样本，不使用24万训练池其余几何拟合初始化。

搜索种子94110；最终三个种子94111/94112/94113同时控制独立的小训练集抽样及网络随机性。validation沿用12000个primitive。最终test及unseen_scale沿用3.1已使用的benchmark，各12000；不是全新confirmation。不能按test改候选、尺度、流场或样本量。

主指标为七条对应路径线31个非初始时刻的三维位置RMSE/初始邻居半径r，与3.1完全相同。每流场三个种子均值，再对九流场等权平均；所有流场与样本量均须报告，不能只挑获胜流场。用户目标为主比较中FMT优于Raw，实际结果须如实记录。

## 预注册候选

网络保持3.1的隐藏宽度512、3个残差块、192维潜变量、只接收潜变量的解码器。每模型固定4000次更新，batch256（小集合不足时截为集合大小）、学习率1e-4余弦降至10%、KL权重1e-5、梯度裁剪1。全量小集训练前不做额外预训练。每500步检查全部validation，只选择正训练步最低误差模型，step0仅作诊断。所有方法使用相同更新预算。

| 正则化编号 | dropout | 权重衰减 | 输入坐标高斯扰动标准差 |
|---|---:|---:|---:|
| 0 | 0 | 0 | 0 |
| 1 | 0.10 | 0.0001 | 0 |
| 2 | 0.25 | 0.01 | 0 |
| 3 | 0.10 | 0.0001 | 0.005r |

dropout插入编码/解码残差网络隐藏激活后，推断关闭；权重衰减作用于可训练参数。输入扰动只改变训练时输入的非初始点，目标仍为干净完整geometry；两臂使用同一物理坐标扰动分布和独立固定噪声种子，然后分别输入Raw坐标或FMT，不能只给Raw加噪声。

每个正则化分别搭配10频与16频signed-FMT，共8候选。16频保留31间隔实信号的全部独立傅里叶系数，是651维可逆变换；10频为3.1的399维有损编码。**16频没有频谱压缩，若获胜只能支持该表示/训练条件下的重建优势，不能直接声称它提高了频谱压缩率。** 两者都通过192维潜变量输出完整geometry，线性初始化所得精度另列。

Raw执行4种正则化候选。Raw无需因FMT频率不同重复训练。搜索为9流场×3样本量×(8FMT+4Raw)=324模型，只读train/validation。

## 选择与最终测试

仅按1024训练样本时九流场等权平均validation RMSE，选择一个跨流场和样本量固定的FMT候选；不按流场定制、不根据Raw变差的程度选候选。同时保留三个Raw比较：

1. `raw_frozen`：3.1无正则化配方，在同一小训练集与4000次预算下重训；24万结果仅作历史参考。
2. `raw_matched`：采用被选FMT候选相同的dropout、权重衰减和扰动。
3. `raw_selected`：四个Raw候选中按相同规则选择validation最佳者，用来检查FMT胜利是否只因Raw未正则化。

候选相同的Raw角色共享同一次训练/评估，报告中注明，不假装独立重复。`selection.json`在测试前冻结并复制为`selection.before_test.json`，然后用三个新种子重训。每个模型仍由validation选择正训练步；validation>=3保存失败并不读取该模型test。测试后不再更改本版本。

所有模型checkpoint仅在内存；最终保存预测NPZ与CSV/JSON，从预测独立复算指标。提交、失败、开始、实际设备和结束登记到`docs/ibex_run_registry.md`；方法结论只写`docs/experiment_log.md`。
