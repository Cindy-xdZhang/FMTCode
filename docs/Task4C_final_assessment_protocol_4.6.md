# mainExp_Task4C_FinalAssessment_4.6

2026-09-13，收束当前开发系列，用用户要求的同一固定测试集检查FMT与Conv3D的实际Hairpin F1。测试目标仍为两模型各自三种子合并F1均值≥0.6；不降低分数、不换标签、不筛除困难样本。

## 相对旧门禁的明确修订

4.1–4.5由助手额外设置“两个方法三种子验证F1均值均≥0.6才进入测试”。它防止开发过程中反复看测试，但验证分数并非用户要求的最终测试分数。这一额外条件使低于门槛的模型始终无法接受实际测试，不足以判断目标是否达成。

旧版本的门禁、选择JSON、源码和历史结果全部冻结。本版作为独立最终评估，条件改为：4.1–4.5的三种子开发选择全部完成，且都未打开最终测试；只按这些验证结果固定方法后进行一次测试。若某源版本通过旧门槛并已自行启动测试，本版拒绝提交，先处理原有测试链。该修订不把验证得分当作测试成绩，也不宣称目标更容易达成。

## 冻结方法选择

每种方法分别比较4.1、4.2、4.3、4.4、4.5已选候选的三种子验证F1均值，取最大者，平局按验证平均精确率。全部对应同一3000束验证样本；提交前从保存概率复算三种子统计，并逐值核对标签/流场/头区/尺度身份。保存各版本候选、原科学commit、原config/selection/cache哈希及最终选择锁。

根据4.1–4.4完整结果，4.1/4.2均已被后续版本同方法的验证均值超过；实际获选只能来自4.3–4.5。适配器仍显式检查这一事实，若实际优选不被支持就拒绝，绝不改选较差候选。4.5未结束前不提交。本版不添加新的训练技术或超参数。

## 最终训练和评估

每个方法直接调用其被选中版本的冻结训练函数。数据预处理、结构、损失、增强/配对策略、学习率、dropout、weight decay、epoch上限和早停规则全部沿用所选配置。只把输出目录、实验版本和最终随机种子替换为本版值，并在独立进程适配最终计划/证据记录函数；源码不改写。

三个全新种子95811/95812/95813，各方法一个共享Channel+TBL模型；仍用27,000拟合与3,000验证选择该种子的epoch和阈值。两方法各自复制所选版本的训练/验证缓存并检查原哈希。无训练权重落盘。

测试完全固定为4.1已生成的Channel5,000+TBL5,000束，六个未见尺度元组，原标签与空间/完整头区/GT实例/原生节点隔离均保持。使用4.3冻结编码函数，选模锁定后才编码测试；各训练函数在拟合及验证阈值确定后才加载测试预测。两个方法与三种子必须使用逐值相同的测试样本身份。

完整报告合并/分流场/每头区/分尺度F1与平均精确率、三种子均值和样本标准差、混淆矩阵、逐样本概率、配置及设备。真实GT实例数量与多尺度视图数量分开。测试空间曾用于3.1，仍是已有benchmark，不宣称新的流场泛化证据。

最终测试结果不用于回改本版选择、阈值、epoch、标签或测试数据；没有自动重测/重新选模分支。若未达0.6，如实保留失败结果，不能凭目标值把协议改成更容易通过的测试。
