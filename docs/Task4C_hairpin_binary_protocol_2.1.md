## 2. 数据和标签

只使用用户指定的Channel原场与GT，不读取TBL。
坐标x为主流方向、y为展向、z为壁法向，壁面在z=-1。源原场为`256×192×256`局部裁剪，不添加周期接缝。

- 原场SHA256：`c1e3c18d0e67b6eb33ea41cd49c3a4c55216838a0f4a42f778ef00aaba3d4564`。
- GT SHA256：`b9fdd93a1d2861781f824f28c80e46e06ebd3e5dcb58f0529010d7514e8fac09`。

候选位置为原始网格单元中心，八顶点线性插值得到`lambda2<-13.395`者为涡区域候选；阈值沿用所给论文表1的Channel small值。
本版不将GT正区域额外强行加入候选，也不套用Task3的IVD p95或Task4-b的IVD阈值。
因此评估总体是满足该涡判据与空间范围条件的候选，不是全场所有位置。

使用原始GT的精确单元包含查询：找到任意GT单元就是Hairpin，未找到就是本benchmark的Non-hairpin。
**GT的74个实例编号包含0；0是有效实例，背景在本版内部使用-1。** 这不追溯改写旧Task4-b的73正编号协议。
GT外的负类是“未被当前GT标为hairpin”，不能据此证明所有未标注结构在物理上均非hairpin。
理想头/颈/腿符号规则不参与标签生成；旧部位标签和论文四类质量标签均不参与。

## 3. 空间划分与样本

按原始x范围固定划为前60%训练、中间20%验证、最后20%测试。
用每个完整GT实例的全部单元顶点计算包围盒；跨任一划分边界的实例全部排除，不能拆为多个集合，也不能将其改标为负类。
每个集合内候选中心还需离集合边界、原场y/z边界至少`R+该轴最大原生网格间隔`。
其中`R=邻居半径+16×积分步长`是所有七线积分及RK4中间查询的解析支撑上界。
准备阶段记录实际查询范围对应的原生x节点编号，并强制三集合不共享任何原生插值节点；完整实例ID也必须两两不相交。

每集合先均匀抽取最多120000个原生涡单元中心，排除跨界实例后均匀抽至train/validation/test最多30000/7500/7500个。
抽样不按类别平衡，不按模型输出选点，种子94201加集合编号；每类至少32个有效样本。
统计是**原生网格单元中心计数**，不是按物理体积加权；非均匀z网格的采样权重须保留此说明。
原始样本、无效积分、实际类别数与实例覆盖均写入准备记录。

## 4. 两方法共有的曲线输入

使用原场已有`vorticity`字段，单位方向上的四阶Runge–Kutta积分（RK4）前后各16步，中心加x±、y±、z±，每条33点。
步长为原始壁法向跨度的0.003125倍，邻居距离为0.005倍，总支撑半径为0.055倍跨度。
沿原始完整流场积分，**不沿GT边界截断，不按GT形状生成线簇**。种子涡判据也不限制后续轨迹必须停留在涡区。
两个方法共享逐样本完全相同的七线33点坐标。

坐标减中心种子，再除固定支撑半径R，输入限定于`[-1,1]^3`；不送入绝对位置、原始速度/涡量数值、GT编号或标签。
正的全局向量幅值缩放不会改变单位方向积分的几何；坐标/积分尺度同倍缩放后该归一化也保持。
这不声称对任意时变参考系客观。
零向量、越界或非有限积分明确标为无效；任一集合有效比例不足99%则准备失败。模型比较使用双方共同有效样本，另报全部候选的有效率和正类覆盖。

## 5. 两个固定模型

多层感知机（Multilayer Perceptron，MLP）由全连接层与非线性激活组成；三维卷积（Conv3D）在体素网格的三个空间轴上提取局部模式。

| 方法 | 表示与网络 |
|---|---|
| `fmt_mlp` | 原冻结`DFT_FMT_3D.py::pathline_dft_features_3d`，6频、gram、手性、邻居sort、scale100、weight0.5，161维；训练集均值/标准差归一化；MLP 161→256→128→1，ReLU、dropout0.1 |
| `conv3d_mlp` | 将同一七线簇三线性投射至24³体素，4通道为占据率与有符号平均单位切向量xyz；Conv3D 4→8→16→32，3³核、GroupNorm、ReLU，两次MaxPool；AdaptiveAvgPool至2³，MLP 256→256→1、dropout0.1 |

每个折线段四等分并含两端采样，体素占据率截至1，切向量按落点权重求均值。
基线是真正的三维空间卷积，不把“线号×采样点×坐标分量”冒充三个空间轴。
两方法参数量分别记录；这不是严格等参数结构实验，不预设FMT获胜。没有第三套网络、混合专家或超参数搜索。
2.1固定实现的FMT＋MLP为74,497参数，Conv3D＋MLP为84,361参数；后者比前者多约13.2%。
体素投射在GPU使用scatter加和，浮点累加顺序可能有细微差异；固定种子不等同于跨GPU逐位一致。

## 6. 训练、选模和结果

三个种子94211/94212/94213，两方法共六次训练。共同设置：AdamW、lr1e-3、weight decay1e-4、batch128、最多100epoch、梯度范数上限1、余弦学习率降至1e-6。
损失为二分类交叉熵，正类权重仅按训练样本`N_negative/N_positive`计算。
不做类别含义不确定的旋转或反转增强。

平均精确率（Average Precision，AP）评估正类分数排序。按最高验证AP选epoch，连续20epoch未改善则停止，严格改善才更新。
选定epoch后，在验证集选择最大F1阈值，平局取更高阈值；F1为精确率和召回率的调和平均。
之后才首次加载test文件并评估。测试集不参与标准化、训练、早停或阈值选择。
最好模型仅在内存保留，不写checkpoint。输出逐次测试概率、验证概率、标签、源单元编号、参数数、训练曲线、设备、配置/代码/数据哈希、F1/AP/平衡准确率/混淆矩阵。
全部六次完成后汇总均值、样本标准差及同种子FMT减基线的差值；不读取部分测试成绩挑选方法。
所有方法级结论只写`experiment_log.md`，不能把本实验与Task1/2/3/5主表混合平均。
