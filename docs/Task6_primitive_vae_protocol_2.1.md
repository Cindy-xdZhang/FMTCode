# Task6：单流场、多尺度 primitive 的 VAE 几何重建 2.1

2026-09-10，按用户新定义更新。实验版本为 `mainExp_Task6_PrimitiveVAE_2.1`；当前只推进Task6。本文件固定任务、数据与评价语义，第7节记录训练前冻结的数值配置。现54组训练及最终1566项指标复算均已完成；实测结论见`docs/experiment_log.md`的同名完成节，作业记录见`docs/ibex_run_registry.md`。

## 1. 唯一目标

每个神经网络只在一个流场内训练，学习该流场中不同时间、位置和尺度的路径线簇几何。不同流场分别拟合网络、预处理统计与潜变量分布；不混合多个流场训练一个共享模型，也不以跨流场迁移作为本任务目标。

流程固定为：

`七条路径线的完整几何 → 冻结FMT编码 → token → VAE编码器 → 潜变量 → VAE解码器 → 同一簇七条路径线的完整几何`

变分自编码器（Variational Autoencoder，VAE）学习一个潜变量分布，并由潜变量重建输入对象。这里**VAE编码器接收token，VAE解码器输出geometry**；重建误差必须在路径线坐标上计算。不能只重建FMT特征，然后把特征误差称为几何重建误差。

测试输入是训练和模型选择均未使用过的一个primitive token；目标是恢复这个token所编码的那七条路径线。测试时从这七条完整路径线计算token是任务规定的合法输入，不是要求网络预测未观测的未来。

| 对比项 | 旧 Task6（保留历史） | 当前 Task6 2.1 |
|---|---|---|
| 编码对象 | 七条可见支持路径线 | 待重建primitive自身的七条路径线 |
| 重建对象 | 其他播种点产生的新粒子轨迹 | 输入token对应的同一簇七条轨迹 |
| 网络任务 | token、query位置、时间 → query位置 | token → VAE潜变量 → 完整七线几何 |
| 一个测试样本 | 支持primitive与未输入的query | 完整未见primitive及其token |
| 训练目标 | query轨迹位置误差 | 七线几何重建误差与VAE分布正则项 |

旧 Task6 查询器、缓存、实验编号和已记录指标不修改，不与新任务混合比较。Task7/8暂不推进；旧Task8依赖的是旧Task6逐粒子查询器，不能因Task6改名而自动改接本版VAE。

## 2. 原始时间范围与完整积分

令 `T_min`、`T_max` 为任务裁剪之前完整源时间序列的起止物理时间，`T_span=T_max-T_min` 为总时长，`t0`为primitive播种时刻。原始范围及源帧索引必须写入数据清单，禁止对已截取的窗口文件重新计算百分比。

| 流场 | 允许播种范围（含边界） |
|---|---|
| 一般非定常3D流场 | `T_min + 0.10*T_span ≤ t0 ≤ T_min + 0.80*T_span` |
| cylinder / half-cylinder系列 | `max(7.0, T_min + 0.50*T_span) ≤ t0 ≤ T_min + 0.80*T_span` |

Cylinder保留项目已有的`t0≥7`约束；当前Re160/Re640/Re6400原始区间均为`[0,15]`，故本版播种范围是 **`[7.5,12]`**。Re640的现有文件从7.5开始，仍按原始`[0,15]`计算，不能再截一半。

上述比例限制的是**播种时刻**，不是强制把所有路径线终点裁到80%。设数值积分时间步长为`h`，积分步数为`N`，则总积分时长为`H=N*h`，向前积分终点为`t0+H`。整个区间及速度场插值所需源帧必须可读，并满足所属数据集合的时间隔离。即使播种时刻合规，也不能在积分不足时缩短轨迹、重复末点或补零伪装成完整样本。

七条轨迹全部完成请求的积分、保持有限值且满足有效流体域约束后，整个primitive才有效。一条失败则整簇按统一物理规则处理；记录候选数、保留数及每类排除原因，不按涡标签、模型误差或图片外观选择样本。

本段时间策略仅新增于Task6 2.1；不追溯改变Task1–5及旧Task6/7/8结果，不把本任务的80%上限误写成所有任务的全局规则。

## 3. 多时间、多位置、多尺度 primitive

每个primitive固定为中心线和初始`x+、x−、y+、y−、z+、z−`六条邻居线，共七条。初始邻居距中心为`r`；不是24邻居或其他线数。

从合规时段内大量不同起始时间和空间位置播种，增加的是**不同primitive的数量**，不是在少数固定primitive周围增加query粒子。以覆盖合规原生时间片和有效空间域为目标；采样密度、随机种子、候选数及最终有效数量按时间和尺度完整记录。

沿用Task5的尺度定义和积分实现接口：

| 量 | 定义 | Task5字段 |
|---|---|---|
| `r` | 中心到六个邻居种子的物理距离；空间倍率乘源网格最小间距 | `offset_grid_scale` |
| `h` | 数值积分一步跨过的物理时间；时间倍率乘源帧时间间隔 | `dt_scale` |
| `N` | 数值积分步数 | `integration_steps` |
| `H` | 总积分时长，等于`N*h` | 派生值，必须显式记录 |

不能将“改变数值积分步长”和“改变轨迹总时长”混为一谈：不同`h、N`可能给出相同`H`。本版需要不同`r`和不同`H`，同时记录完整三元组`(r,h,N)`。尺度分配不使用IVD或人工类别，每个时间片中各尺度候选数量尽量均衡。

起始参考表为 `config/mainExp_Task5_3D_1.1.yaml` 的尺度值（例如训练邻居距离倍率0.25/0.50/1.00，总时长4–12个源帧间隔），不是复用其旧时间片或IVD标签。实际Task6尺度表须经时间覆盖预检后在新配置中独立冻结，不静默改Task5配置或继承旧缓存的早期Cylinder样本。

数值积分沿用四阶Runge–Kutta方法（RK4）。不同积分步数得到的轨迹统一按归一化物理时间重采样为每线32点，包括起点和终点，得到`7×32×3`坐标数组；不改成弧长重采样，不打乱粒子身份或时间顺序。实现参考 `FMT_Utils/MultiscalePathline_3D.py`。本版“完整轨迹”指请求的完整积分区间上这32个固定采样点；原始积分点数和物理时刻另存，不宣称恢复任意连续时间细节。

## 4. 几何、token与潜变量的区别

沿用已有局部坐标约定：对同一primitive的全部点只减去**初始时刻的中心位置**，再除以初始邻居距离`r`。该`7×32×3`数组是本版要重建的geometry；它保留后续中心运动、原空间朝向、邻居身份及每个时刻的位置。

不在每个时间片分别减去当时中心，不对各条线单独平移或旋转，不用真实目标为预测选择最佳旋转或粒子排列来降低主误差。原始起点、`r、h、N`和物理时间作为数据元信息保存；如展示实验室坐标，用记录的初始中心与`r`恢复，不能宣称绝对位置由token独自恢复。

FMT token和VAE潜变量是两个不同阶段：

- **FMT token**：冻结几何编码的输出，无可训练参数。首个核心方法使用原`fmt_all`；七线、六频、Gram特征和邻居排序等原定义保持。代码为 `FMT_Utils/DFT_FMT_3D.py::pathline_dft_features_3d`，输出161维。送入FMT的局部几何及全部缩放必须与新配置一致，不能把旧任务中的不同预处理混用。
- **VAE潜变量**：由可训练VAE编码器从token推断的较低维表示。训练时编码器给出潜变量的均值和方差，由此采样；解码器直接输出七线坐标。
- **几何输出**：固定`7×32×3`，对应输入primitive的七条完整路径线。测试解码器只得到潜变量，不额外接收真实中心全轨迹、Raw几何或未在协议声明的运动旁路。

VAE损失由几何重建项加上分布正则项组成。几何重建项覆盖七条线和整个采样时间区间；分布项采用Kullback–Leibler散度，衡量编码器给出的潜变量分布与标准高斯先验的差异，权重记为`beta`。正式VAE的`beta`必须为正；若另做零权重普通自编码器，应作为独立消融，不改名冒充VAE。

本版不继承旧查询任务“只监督偶数时刻、奇数时刻作为插值测试”的设置。确定性主测试用潜变量均值解码；如展示随机生成样本需单列，不能看真实几何后从多次采样中挑误差最小者作为主结果。

## 5. 训练、验证与测试

拆分单位是完整primitive和其来源时间组，不是轨迹中的点，也不是七条线。先划分源时间块，再生成几何；数值积分及速度场时间插值所使用的完整源窗口必须包含在所属集合中，训练、验证、测试源窗口不重叠。同一播种来源的尺度变体、重复采样、增强版本一起分组，不能跨集合。

主测试评估同一流场内、未用于训练或模型选择的primitive重建；主比较中允许训练与测试使用相同的尺度取值，以单独回答未见几何的重建能力。另列训练未见尺度组合的重建测试，分别说明组合插值和外推；不把未见尺度成绩与主测试混成一个数字。所有拆分与尺度表在正式训练前冻结，不以test成绩选配置。

两个核心比较方案固定为：

| 方案 | VAE编码器输入 | VAE解码器输出 | 所回答的问题 |
|---|---|---|---|
| `fmt_all_vae` | 同一七线geometry经原FMT得到的161维token | 七线geometry | FMT输入是否有助于学习该流场的primitive几何分布 |
| `raw_vae` | 同一七线geometry展开的672维坐标 | 同一七线geometry | 不经FMT的直接几何自编码参照 |

两臂使用相同训练primitive、几何目标、潜变量维数、解码器、编码器隐藏结构、损失权重、优化器和训练曝光预算；输入层因维数不同而改变的参数量如实报告。所有预处理统计仅由本流场训练数据拟合；不沿用旧Task2的token重建输出头或KMeans评价。当前先完成这两个核心方案，不扩展到Task7/8或把其他编码器混称为原FMT。

先检查有限训练primitive的完整几何拟合，再在大规模数据上训练。至少三个优化随机种子，训练/验证曲线与最终测试分别保存。拟合检查只能说明拟合能力，不能替代未见primitive测试。网络宽度、潜变量维数、`beta`、样本量、优化器、更新预算及模型选择规则属于下一步需在运行配置冻结的数值项，不从已读取的旧Task6测试指标选择本版test样本。

## 6. 评价、可视化与结论范围

主指标是七条对应路径线全部非初始采样点的三维位置均方根误差，以初始邻居半径`r`为单位。七条线和各时间点等权，保持固定粒子与时间对应；初始点误差另列。另保存全采样点重建误差、中心线/六邻居分项、各时刻误差、终点误差及同时间所有粒子对距离误差，逐流场、尺度、时长和随机种子汇总。

图中展示同一个未见primitive的真实七线、Raw-VAE重建七线、FMT-VAE重建七线，使用相同相机和取景范围，并标记时间顺序。固定样例选择规则，不挑选最有利的几何；较大误差样本和失败尺度仍进入汇总。

本任务检验的是**FMT是否帮助VAE学习和重建路径线簇几何**，没有IVD分类标签，也没有额外query粒子的监督。用户提出的“现有FMT更适合几何模式学习”作为研究假设保留，不预写成已证实结论。完整复系数的傅里叶变换可逆；当前编码的截频、旋转不变量和邻居排序是不同的信息处理步骤，应分别判断。VAE可以学习几何分布，但不能保证唯一恢复编码中已经丢失的信息；重建误差仍需实测，不能因为改为自编码就承诺成功。

正式实现沿用项目的版本、test隔离与结果留存规则。每个Ibex进程登记 `docs/ibex_run_registry.md`；方法级实测结论只记入 `docs/experiment_log.md`。模型checkpoint不作长期保存或下载。旧查询任务的源码和3375项已审计记录保持原样。

时间块先按源元数据确定。完整最大窗口为13帧；只保留13帧全部可读且播种时刻合规的候选。寻找接近可用范围60%/80%的两个时间边界，并要求train/validation/test分别至少两个合规起始时间、完整插值帧互不重叠。同一集合内窗口可重叠。每个时间×尺度格尽量均衡分配样本，数量差至多1；固定随机位置，整簇七线均物理有效才保留，最多尝试目标数量40倍，不足则作业失败并记录，不静默减少样本。

元数据预检显示：Cylinder三例各18个train起始时刻、2个validation、2个test（物理时刻分别7.5–9.2、10.5–10.6、11.9–12.0）。其他流场train起始时刻数量分别为Tangaroa 80、DeltaWing resampled 67、DeltaWing LBM 42、F22 52、Boeing747 36、SmokeBuoyancy 62。验证和测试的时间覆盖较少是本次严格窗口隔离的限制；不能把6,000个测试primitive写成6,000个独立时间片。

源范围以任务采样前完整提供的时间轴为依据；Cylinder按原模拟[0,15]恢复，Re640文件索引0映射到原索引75。稀疏导出文件保留原时间轴并检查明确可用索引，缺失帧不插补。SmokeBuoyancy使用所提供`80_239`文件的完整时间轴[2.6811783,8.0100203]，这不是声称掌握更早的完整模拟。原始时间坐标、文件大小/修改时间、可用索引、窗口索引与加载坐标都进入清单。

读取阶段保留masked voxel为非有限值，禁止旧加载器补零后产生伪静止轨迹。RK4各内部阶段检查空间边界；任一轨迹遇到非有限插值则整簇排除。保存物理时间均匀重采样后的完整32点；源窗口与目标积分长度分别记录，不假装每个尺度均积分12帧。

提交顺序为CPU单元测试/时间预检 → 九流场数据构建（最多3并发）→ 数据审计 → 54个独立GPU训练（9流场×2臂×3种子，最多6并发）→ 从全部预测重新计算指标的最终审计。前序失败则后续不启动。所有结果保存配置hash、代码commit、数据hash、训练曲线、逐尺度指标和几何预测，模型不落盘。
