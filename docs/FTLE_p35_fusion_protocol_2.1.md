# Other_FTLEP35Fusion_2.1

2026-09-15，用户要求从分类中的p35逐特征均值＋最大值出发，寻找4×、8×超过ESPCN/U-Net的FTLE超分辨方法；傅里叶变换必须真实作用于输入线簇。历史1.1/1.2冻结。

## 来源和第一性原理

分类方案依据`docs/FMT_p35_h0_structure_2.2_zh.md`及科学commit bc09a242。p35是中心描述量＋中心坐标/切向频谱＋邻居逐特征均值/数值最大值；分类网络及输入归一化随任务不同。正在进行的归一化/频率3.1搜索不作为已完成结论使用。

FTLE=log(sigma_max(J))/|tau|，J为流映射对初始位置的导数。单个FTLE值丢失拉伸方向、另一个奇异值及沿时间的变形过程。五线簇可提供这些额外信息。当前低分辨率FTLE本身已使用±x/±y四邻居终点，与FMT共用这五条物质线，因此不能把新收益解释为本轮比旧基线多积分了四条线。传统只积分格点中心再差分的成本是另一种定义，不混入本次比较。

保留带符号且有线身份的傅里叶系数可以补回p35池化丢失的方向。中心步进及邻居相对步进的DFT零频为整段变化之和，包含末端位移/形变；非零频提供过程信息。这个关系用于检验输入的信息完整性，网络仍学习高分辨率FTLE，不作傅里叶逆变换恢复高分辨率轨迹。

架构参考：[ESPCN](https://arxiv.org/abs/1609.05158)的低网格卷积＋像素重排；[EDSR](https://arxiv.org/abs/1707.02921)的残差预测、不用BatchNorm及残差缩放。新模型不是这两篇论文的完整复现。另调研[LIIF](https://arxiv.org/abs/2012.09161)的局部特征/相对坐标解码；本轮先检验计算更便宜的固定倍率像素重排。

## 五线二维p35适配

五线顺序固定中心、x+、x−、y+、y−，每线32点，绝不添加z邻居或把t当z。
中心几何减整束质心、除整束最大半径R；邻居相对向量除初始邻居平均半径r0。前者稳定运动幅值，后者保留无量纲拉伸量。各几何臂附加相同log(R/r0)，原始路径线对照使用同样的坐标和尺度信息。

每频率提取实部范数、虚部范数、二者余弦；二维三重积恒零，明确移除这些零槽，不另造三维手性。保留6频，中心18＋方向48＋四邻居逐列均值18/最大值18=102维，再加尺度1。邻居均值/最大值在标准化前计算，最大值不是绝对值最大值。

## 网络与公平对照

两个下游网络：低网格空洞卷积残差网络（局部感受野逐级扩大）和无BatchNorm的两层U-Net式金字塔。都融合当前全幅有效低网格上的隐藏特征均值/最大值，提供全场上下文；训练和推断均为完整时间切片，避免训练patch与推断全场的统计范围不一致。
初始输出是固定节点坐标双三次插值，网络预测修正量；重建后已知低网格节点强制等于输入。所有新臂共享该约束。几何补零至672列，所有几何臂和none的参数张量形状、数量、初始化完全相同；活跃信息量不同。新结构不声称参数量与历史ESPCN/U-Net完全相同，单独报告成本。

## 数据与模型选择

沿用1.2四流场、4×/8×、同一高网格、32点五线、tau1、offset0.005和共同评价掩码。复用已存在的train/validation/test，不新建第三份数据；保留历史文件角色。全部训练及选择只读取train/validation。最终方案固定后才读取旧test，每个最终模型一次；该test已在1.1/1.2使用，不称为全新确认集。完整积分时间及源插值帧跨集合无交集。

先做9个候选：pyramid下none/raw/p35/signed/p35_signed/p35_multitime六臂，unet下none/raw/p35_multitime三臂。仅含p35的四个候选有资格成为主方法，其余为架构/信息对照。每个流场和倍率单独训练，结构/输入候选统一跨流场和倍率选择，禁止按test逐场择优拼接。
开发种子98201。新臂固定最多800次更新、batch2完整切片、AdamW学习率0.001、weight decay1e-5；每20步用整场验证MSE选模型，100步无改善停止，验证调度学习率。所有已尝试候选包括失败与负结果保留。ESPCN与U-Net按冻结1.2无dropout、原patch/训练规则复跑开发参照。
全部新臂把step0的零修正模型也纳入验证选择；它们共享同一个初始双三次预测。
主选择量为四流场×两倍率等权验证PSNR；同时分别报告4×和8×相对两参照的变化。主方法必须在两倍率分别超过两参照，且对应结构下优于无几何对照，才进入三种子确认；未达标仅报告开发状态并在新版本记录后续修订，不偷偷读取test调参。
最终种子98211/98212/98213；统一选定候选、同结构none/Raw/p35/signed对照及冻结ESPCN/U-Net复跑。全部主表来自test，逐流场逐倍率完整报告。优于ESPCN不自动证明p35有效，必须结合这些对照解释。
