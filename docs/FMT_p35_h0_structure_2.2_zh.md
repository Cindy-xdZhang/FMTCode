## 输入与任务区别

- Task3/5：每个primitive为7条线×32个采样点×3坐标，包含一条中心线和六条邻居线。每个流场分别训练模型；同一p35/h0配方跨十个流场保持。Task3/5是IVD涡区二分类，不是涡类型多分类。
- Task4-c 4.14：每束10–27条有效涡线，每线按弧长重采样32点；沿涡量向量场积分，不能称为非定常速度pathline。整束减去所有有效点的质心，再除以这些点到质心的最大距离。每条有效线轮流作中心，按播种点距离选六条最近的有效邻居线，形成局部7线输入；不足27条的位置补零。
- Task4-c的采样轴是沿曲线的点序号；Task3/5这里的傅里叶实现也以存储点序号为轴，不把频率格点直接解释为物理Hz。

## 中心23维：DFT之后的几何描述量

设中心为x_0[n]，邻居为x_i[n]，n=0,…,31，i=1,…,6。中心输入序列为：

\[
u_0[n]=x_0[n+1]-x_0[n],\qquad n=0,\ldots,30.
\]

它是31个三维步进向量，不除以时间间隔。对31点序列作离散傅里叶变换（Discrete Fourier Transform，DFT），保留k=0,…,5六个频率：

\[
F_k=\sum_{n=0}^{30}u_0[n]\exp(-2\pi i kn/31)=a_k+i b_k.
\]

a_k、b_k分别是三维实部向量和虚部向量。默认DFT不除以31。每个频率保存三项：

\[
\|a_k\|,\quad \|b_k\|,\quad
\frac{a_k^\top b_k}{\max(\|a_k\|\|b_k\|,10^{-8})}.
\]

六频率得到18维，再追加五个有符号的归一化三重积：

\[
c_k=\frac{(a_k\times b_k)^\top a_{k+1}}
{\max(\|a_k\|\|b_k\|\|a_{k+1}\|,10^{-8})},
\quad k=0,\ldots,4.
\]

合计18＋5＝23维。前18维按每个频率的“实部范数、虚部范数、两者余弦”排列，最后5维为三重积。这里的余弦不是fmt_v5新增的15个同时间邻居夹角。

DC频率的虚部为零，因此23维中索引1、2、18是理论固定零槽位，历史实现保留这些位置。

## 邻居138维与p35的46维池化

先计算同一采样位置的邻居相对向量及其跨采样步变化：

\[
d_i[n]=x_i[n]-x_0[n],\qquad
u_i[n]=s(d_i[n+1]-d_i[n]).
\]

每个u_i同样用上一节的DFT＋18项描述量＋5项三重积得到23维。六个邻居得到6×23矩阵，原实现对每一列分别将六个值降序排序，再乘权重w，按排序名次优先展平为138维。

实际适配参数必须按任务区分：

| 项目 | Task3/5 | Task4-c 4.14 |
|---|---|---|
| 原161维来源 | 原始冻结缓存，保持历史算术 | 归一化涡线束的局部7线 |
| 邻居步进倍率s | 1 | 100 |
| 邻居描述量权重w | 1 | 0.5 |
| 几何归一化 | 原161维保持缓存；新方向分支单独归一化 | 整束质心与最大半径归一化后计算全部分支 |

“141维相同”不意味着这些任务的输入适配数值完全相同。

p35将138维重新看成M∈R^(6×23)，对每列分别求：

\[
\mu_j=\frac{1}{6}\sum_{i=1}^{6}M_{ij},\qquad
m_j=\max_{i=1,\ldots,6}M_{ij},\quad j=1,\ldots,23.
\]

输出23个均值＋23个最大值＝46维。最大值是按数值比较，不按绝对值比较；均值保留符号。排序后的同一行不一定来自同一物理邻居，但同一列始终是同一类描述量。数学上均值和最大值不受先前排序影响；本次实现仍读取原冻结缓存。

这里先池化后标准化，不是在标准化后的138列上求均值或最大值。没有保留原V8的“全局幅值前4项＋全局均值”；没有增加fmt_v5的165维角度分支。

## 坐标／切向方向频谱72维

用归一化后的中心线q[n]构造：

\[
t[n]=\frac{q[n+1]-q[n]}{\max(\|q[n+1]-q[n]\|,10^{-12})},
\quad n=0,\ldots,30;\quad t[31]=t[30].
\]

每个点拼接(q_x,q_y,q_z,t_x,t_y,t_z)，得到32×6数组。沿32点轴作正交归一化实数FFT，即使用1/√32归一化，保留k=0,…,5，并保留每个复数的实部和虚部：

6个频率×6个通道×实部/虚部2＝72维，展平顺序为“频率、通道、实/虚”。

Task3/5仅为这个方向分支使用整个7×32点primitive的质心和最大半径；中心23和邻居138保持原缓存。Task4-c的q来自前述整束归一化。72维保留坐标方向信息，整套p35不宣称时变参考系客观。

| 左闭右开切片 | 内容 | 维数 |
|---|---|---:|
| [0:23] | 中心步进的DFT描述量 | 23 |
| [23:95] | 坐标／单位切向方向频谱 | 72 |

固定编码器无可训练参数。141是保留的数组宽度：中心、均值、最大值各有3个理论零槽，方向分支有6个DC虚部零槽，共15个固定零槽；不能说141个槽位都是独立非零信息。没有梯度/curl/IVD估计附加特征。

## Task4-c实际网络

每条线的141维先做带符号对数变换sign(f)·log(1+|f|)，再用全部训练样本中有效线的逐维均值、标准差归一化，裁剪至[-8,8]。标准差小于1e-8的列按1处理。无效线归零；标记不进入线性层。

输入张量[B,27,142]含标记。逐线共享的多层感知机（Multilayer Perceptron，MLP）为：

~~~
141 → Linear(141,128) → LayerNorm(128) → GELU → Dropout(0.15)
    → Linear(128,128) → LayerNorm(128) → GELU
~~~

LayerNorm按单条线的隐藏通道归一化；GELU为高斯误差线性单元激活。随后只在有效线之间，分别对128个隐藏通道求均值和最大值，拼接为256维，分类头为：

~~~
256 → Linear(256,128) → LayerNorm(128) → GELU → Dropout(0.15)
    → Linear(128,64) → GELU → Linear(64,2)
    → Softmax → Hairpin概率 → 固定0.5阈值
~~~

两次平均/最大池化的位置不同：固定FMT里的池化是每条中心线的六邻居描述量；网络里的池化是整束有效线的128维学习表示。

逐线网络35,200参数，分类头41,538参数，共76,738，全部在训练阶段可训练。h0使用AdamW、学习率0.001、weight decay=0.0001、batch=128、最多500轮，连续50轮未改善停止；学习率调度器ReduceLROnPlateau监测验证损失，patience=15、factor=0.5、min_lr=1e-6。损失为两类交叉熵，梯度范数裁剪5。每轮用验证固定0.5阈值F1选模型，F1相同时比较平均精确率。

0.727056对应种子96611，训练91轮，选用第41轮。后续三种子最终测试是不同的重训运行，不能与该验证数混称。

## Task3/5实际网络

这两个任务使用原始轨迹网络＋FMT残差分类器，不是只将141维送入一个独立分类器。

Raw表示直接读取7×32×3坐标的网络。先只用训练数据估计每个坐标通道的均值/标准差。每条线共享一维卷积：

~~~
3×32
 → Conv1d(3,32,kernel=5,padding=2) → GroupNorm(4组) → GELU
 → Conv1d(32,64,kernel=5,padding=2) → GroupNorm(8组) → GELU
 → Conv1d(64,64,kernel=3,padding=1) → GroupNorm(8组) → GELU
 → 沿32点分别求均值/最大值 → 每线128维
~~~

GroupNorm表示在每个样本内部将通道分组归一化。取中心线128维、六邻居均值128维、六邻居最大值128维，拼接384维，再Linear(384,128)＋LayerNorm＋GELU得到几何表示g。Raw分类头为Linear(128,128)＋LayerNorm＋GELU＋Linear(128,1)，输出z_raw。

Raw先训练并按原验证规则选轮次，然后冻结，其参数89,921。FMT分支为：

~~~
固定141维 → 追加292个零至433维 → 按训练样本逐列标准化
          → Linear(433,64) → LayerNorm(64) → GELU → a∈R^64
~~~

此处没有Task4-c的带符号对数或[-8,8]裁剪。补零列只是保持此前各表示的同等名义参数量，不是新增292个几何量。辅助分支27,904参数。

残差头为：

~~~
拼接冻结g(128)与a(64)：192
 → Linear(192,128) → LayerNorm(128) → GELU → Linear(128,1)
 → z_residual
最终概率：sigmoid(z_raw + α·z_residual)
~~~

残差头25,089参数；辅助分支＋残差头共52,993可训练参数，总模型89,921＋52,993＝142,914参数。h0没有额外辅助dropout。Raw-wide（加宽Raw参照网络）用于原验证选择流程的参照，不参与最终分类前向计算。

Task3每流场在验证集上从0、0.05、…、3的61个值选择α；沿用原规则比较相对Raw/Raw-wide参照的F1和平均精确率增益，取两项增益的较小值作为选择分数。Task5固定α=1。两任务的分类阈值均由验证标签选择，不是固定0.5；例如本行Task3/Channel的α=3、阈值0.9997215867042542、选定第8轮。

训练使用AdamW、学习率0.001、weight decay=0.0001、batch=512、每阶段最多100轮、patience=20、min_delta=0.0001；二分类损失的正类权重来自训练标签。不把该行十流场平均误称为一个共享网络的结果。

## 后续两集合评价约定

用户希望后续仅保留训练集＋测试/评估集，不额外划分第三份数据；这一数据组织方式可以使用。评价集是否参与梯度更新，与是否用于选择配置、α、阈值或轮次，是不同问题。本次旧验证集已经用于这些选择。

后续新实验可称“测试集”，但若它参与模型选择，必须同时写清“用于模型选择的训练外测试/评估集”；不能描述成整个开发过程未见的独立测试。若参数、阈值和轮次在看该集前固定，则两集合也可给出不参与选择的测试结果。旧验证/测试的文件角色和数值保留，不靠改名改变用途。

数据稀缺不要求机械地固定三份划分，但也不会消除模型选择带来的偏差。[Cawley与Talbot，JMLR 2010](https://www.jmlr.org/beta/papers/v11/cawley10a.html)分析了在评价数据上优化模型选择指标造成的偏差；这一点不依赖输入是自然图像还是流体轨迹。
