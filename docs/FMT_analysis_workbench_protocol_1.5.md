逐GT表格各列的含义：

| 列 | 计算方式 |
|---|---|
| 可用头部束 | 当前集合中，中心属于该真实GT、满足头部夹角条件、标签为正类的全部束 |
| 其中新增 | 这些束中，本次追加的数量；测试每GT10，训练展示每GT30 |
| 实际显示 | 当前模式、区域、类别开关和显示数量筛选后真正画出的头部束数 |
| 正确识别 | 全部可用头部束中，c156的Hairpin概率至少0.5的数量 |
| 漏检 | 全部可用头部束中，c156的Hairpin概率低于0.5的数量 |

正确识别和漏检之和等于可用头部束数，不受显示数量影响。点击某个GT行，会切换到该GT区域并显示其全部头部束。表格按中心在原GT体单元中的实际归属计数；新增束遇到GT重叠时，独立验证其指定播种GT包含该中心后计入该GT。旧束仍按几何查询计数，不把旧整片候选区域的标签归属误当成中心所在GT。点选详情分别显示中心GT与标签来源实例。
