# Task6 3.1 结果与图形导出约定

状态：本文件在真实训练结束前固定导出规则，不预写实验结论。

问题：在同一原始半径单位与固定历史测试轨迹上，修复后的signed-FMT+VAE是否将每个流场重建误差压到1以内？

| 产物 | 代码 | 内容与边界 |
|---|---|---|
| 逐流场/种子汇总 | `experiments/Report_Task6_Reconstruction_3_1.py` | 核对配置、commit、正训练步、实际曝光、validation门槛及2592条指标；分别列新test、未见尺度与legacy_test |
| 原始结果包 | `experiments/Package_Task6_Reconstruction_3_1.py` | 收集JSON/CSV/曲线、实际Slurm时间设备及固定轨迹样例，不含模型文件 |
| 历史数据误差对照图 | `experiments/Plot_Task6_Reconstruction_3_1.py` | 九流场全部进入；每方法三个种子的均值和样本标准差，旧/新测试轨迹相同；不同版本训练集/编码/初始化变化，所以不是单因素消融 |
| 固定primitive四列图 | 同上 | Ground truth、原FMT-VAE、signed-FMT-VAE、Raw-VAE；每流场固定索引0/2000/4000，旧/新分别使用首个预注册种子，全部7线×32点保留，不按误差选样 |

全部采用Python/matplotlib。定量图为单面板，各流场形成同一测试集合的对应比较；示例图为四列对照，每张图四列使用相同视角、坐标范围和物理比例。误差指标保持原单位，不对预测做旋转、点身份排列或时间变换。不画预测边界框，不隐藏脱离真实几何的大偏移。

导出PDF/SVG可编辑矢量文字及600dpi PNG；最终宽度约183mm，字号不低于7pt。每张图导出前调用panel-alignment检查，导出后执行PDF字形字号检查、文字/线条碰撞检查，并检查每个面板和整图。静态检查允许两项已说明提醒：PNG是预览而PDF/SVG是提交候选；对数轴正值检查已显式写入代码。误差标准差区间若跨0则停止该图，不在对数轴静默裁剪。

抽样示例只作几何核对，不能代替九流场全体测试指标。标量结论以`docs/experiment_log.md`及最终审计为准，未运行的图不能称作已验证。
