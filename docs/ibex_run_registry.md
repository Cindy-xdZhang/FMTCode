## 强制登记规则

1. job 提交后立即新增一行，状态写 `QUEUED`；拿到实际开始时间、节点和 GPU 后更新同一行。
2. 完成后把“运行状态与主要结果”更新为 `COMPLETED`、`FAILED`、`TIMEOUT`、`CANCELLED` 或 `INVALID`，并给出主指标或失败原因。
3. “支持/反对的结论”必须写成可证伪句子；失败 job 也必须说明它不能支持什么。
4. 实验版本必须符合 `mainExp_[name]_x.y`、`Verify_[name]_x.y`、`Ablation_[name]_x.y` 或 `Other_[name]_x.y`。
5. 开始时间使用 ISO 8601 并包含时区，例如 `2026-08-23T14:30:00+03:00`。
6. 设备至少记录 Ibex GPU 型号和数量；开始后补实际 node。job array 可登记 array ID，但输出中必须能追踪每个 child task。
7. config、git commit、stdout/stderr 和 output 路径缺一不可。重提交产生新 job ID，不覆盖旧行。
