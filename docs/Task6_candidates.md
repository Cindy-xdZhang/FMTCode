# Task6 候选：检验 FMT 作为 flow map tokenizer

日期：2026-09-09。**后续决定：用户选择全部执行，A/B/C 分别正式登记为 Task6/Task7/Task8。** 实施以 [Task6/7/8 协议 1.1](Task678_flowmap_protocol_1.1.md) 为准。下文保留原讨论稿及当时的建议，不代表仍待选题；字母 A/B/C 不是实验版本号。研究现状和方法结论只记入 [experiment_log.md](experiment_log.md#progress-2026-09-09)。

## 要回答的问题

Fourier Map Tokenizer（FMT）是把一组邻近材料粒子的路径线编码为特征向量的无训练参数编码器。这里 token 指该特征向量，不预设离散词表。Flow map（流映射）把某个初始位置映射到粒子在另一个时刻的位置；一组 pathlines 则在多个时刻采样这个映射。

Task6 希望检验：**给定有限的 token，能否恢复或使用整段材料运动及其相对几何，而不只识别一个初始时刻的物理量？** 目标直接由原流场数值积分生成，无须涡类别或 hairpin 人工标注。下游解码器或上下文网络需要训练；FMT 编码器仍冻结，不能把整个系统称为 training-free。

## 候选 A：可查询的局部流映射重建（优先建议）

**直观例子**：给模型一个由 7 条路径线形成的 primitive token，再指定这个 primitive 初始邻域中一个新粒子的播种位置。模型要恢复新粒子在整段时间里的轨迹。新粒子的实际轨迹由流场积分产生，只用于训练目标或留出评估，不进入输入 token。

| 项目 | 候选设计 |
|---|---|
| 输入 | 单个 primitive 的 token、查询粒子的初始局部坐标、查询时间；各方法共享同样的初始位置、初始尺度及坐标基底信息 |
| 输出 | 未输入粒子在整个已观察时间区间内的位置；包括编码时间采样点之间的查询时刻 |
| 自监督目标 | 从相同初始邻域另外播种粒子，以数值积分轨线作为目标；输入线与目标线保持不同的材料点身份 |
| 主评估 | 同一材料粒子、同一物理时刻的位置误差随时间的曲线，以及全时段平均误差；用固定物理长度归一化 |
| 几何评估 | 多个目标粒子之间同时间距离的误差、局部拉伸及体积变化误差；与完整运动误差分别报告 |
| token 用量 | 比较保存特征所需字节数与重建误差，另报编码/查询耗时；不能只凭“维度更低”声称达到实际压缩 |
| 能支持的结论 | token 是否保留足够的局部流映射信息，支持对未输入材料点进行整段轨迹查询 |

这不是只解码输入的 7 条线，也不是预测已观察时间区间之外的未来。单独重构已有输入可作实现检查，未输入粒子的重建才是主问题。查询位置先限定在初始邻域内，避免把不受观测约束的远处外推混入主评估。

必须加入以原始稀疏轨线为输入的空间插值对照，例如局部仿射插值。如果 FMT 只优于一个较弱的神经解码器，却不能在相同存储或查询成本下接近简单插值，tokenizer 的实用证据仍有限。另设只保留中心轨线或平均平移的诊断对照，用来判断增益主要来自整体输运还是邻居之间的形变。

初始位置/初始坐标基底等公共信息来自可见输入，并计入存储；不能额外提供真实的全时段中心轨迹或目标轨迹。对 FMT 本身已舍弃的量，必须先列明可恢复范围；不能要求一个主动删除平移信息的描述符单独恢复绝对平移，再据此断言它没有相对几何信息。

**建议图**：输入稀疏轨线 → token → 重建的稠密轨线，与积分真值并排；配合字节数—误差曲线和随时间变化的误差曲线。若 FMT 的优势覆盖后半段轨线且相对几何误差也低，这比初始时刻 IVD 分类更直接地支持完整几何表示。

## 候选 B：遮挡区域的流映射补全

**直观例子**：把一个流动区域中的一整块 primitive 隐藏，仅提供周围区域的 token，让同一个上下文网络恢复被隐藏区域中各粒子的完整轨迹。

| 项目 | 候选设计 |
|---|---|
| 输入 | 周围可见 primitive 的 tokens、已知初始播种网格及遮挡位置 |
| 输出 | 隐藏区域粒子的整段路径线，而不只是预测隐藏的 FMT 向量 |
| 自监督目标 | 隐藏区域对应的真实积分轨线，无需类别标签 |
| 评估 | 完整运动与相对几何两类误差，随遮挡区域大小和可见 token 数量变化；独立时间窗口/流场上的结果 |
| 能支持的结论 | FMT tokens 是否适合被共享上下文网络使用，以表达邻近局部流映射之间的关系 |
| 主要难点 | 缺失区域可能不能由邻域唯一确定；网络、训练数据量及简单空间插值都会影响结论 |

与 A 的区别：A 中目标粒子的局部 primitive 是可见的，考查一个 token 内保留的信息；B 把目标区域的 primitive 整体移除，考查多个可见 token 提供的空间上下文。

必须在构造输入特征前确定遮挡，并排除所有包含目标材料轨线的可见 primitive；对相邻 primitive 重用中心线/邻居线的情况，要按材料点身份检查，不能只隐藏显示出来的中心点。使用空间块和隔离带，避免任务退化为从重复邻居中复制目标。不能把隐藏区域的真实 FMT 特征或其全轨线归一化统计送入网络。

方法启发来自点云遮挡自编码器：Point-MAE 把点云分成局部块，用可见块重建隐藏块。此处将目标改成有材料点身份与时间顺序的流映射，是本项目的候选设计，尚无本项目性能证据。[Point-MAE 原论文](https://arxiv.org/abs/2203.06604)

## 候选 C：短流映射 token 的组合

**直观例子**：已知第一段时间和第二段时间各自的流映射 tokens，组合出更长时间的材料运动，并对未输入的粒子执行查询。检验 token 能否作为可重复使用的运动单元。

令 \(F_{a\to b}(x)\) 表示粒子从时刻 \(a\) 的位置 \(x\) 出发，在时刻 \(b\) 的位置。真实流映射满足

\[
F_{a\to c}(x)=F_{b\to c}\bigl(F_{a\to b}(x)\bigr).
\]

即先用第一段映射求出到达位置，再从该位置查询第二段映射。非定常流必须保留起止时间，不能只用时长就假定两个不同起始时刻的映射相同。

| 项目 | 候选设计 |
|---|---|
| 输入 | 两段已知时间区间的局部 token 集及查询粒子；第二段的空间覆盖必须包含第一段的到达区域 |
| 输出 | 组合区间上的粒子位置与轨迹；后续可讨论在更多段数或未见时长组合上评估 |
| 自监督目标 | 从原流场直接积分得到的长区间材料轨线 |
| 主评估 | 对真实轨迹的误差及误差随组合段数增长的曲线；局部形变误差分别报告 |
| 必要对照 | 原始轨线插值后组合、逐段解码后显式组合，以及相同输入信息和存储预算的其他特征编码器 |
| 能支持的结论 | FMT token 是否可作为局部流映射的可组合表示，而不是只在一个固定窗口里有判别能力 |

本候选**已提供两段映射的观测信息，不是从第一段凭空预测未知未来**。若以后研究未来预测，应另立问题，明确可用的过去观测与不确定性。

不能只最小化两个预测结果之间的组合一致性：恒等映射或常量输出也可能得到虚假的低损失，必须用真实积分轨迹评估。输入不能含查询粒子的真实长轨迹或由其生成的长窗口 token；第二段输入使用独立的已知播种网格。

方法背景是流映射的组合结构。Deep-OSG 研究自治动力系统中满足半群性质的演化算子；本项目非定常速度场对应带起止时间的两参数映射，上面的组合式适用，不能直接照搬自治假设。这里是实验构思，不声称完成该论文复现。[Deep-OSG 原论文](https://arxiv.org/abs/2302.03358)

## 三个候选共同需要的比较

1. **编码器分开命名**：原 FMT、客观 Gram–Fourier 版本、`aivd1w3_dft` 都保留独立实现与结果。基线包括原轨线、主成分分析（PCA，以线性投影保留主要方差）、变分自编码器（VAE，用重建目标和潜变量正则学习表示）、传统微分几何描述符，以及直接对坐标序列取 Fourier 系数的对照。各基线的完整配方在选定任务后冻结。
2. **公共解码任务**：所有表示使用相同目标、可见材料线、训练数据与公共坐标信息，匹配 token 存储用量和解码网络容量，报告实际参数量。PCA/VAE 及任何适配器只能在训练集拟合。不能用更大的 FMT 解码器代替表示比较。
3. **全时间段计分**：按时间报告误差并单独展示后半段，避免大量容易的初始样本主导平均；损失和窗口权重在测试前确定。时间点之间的误差保持物理时间对应，不能用无序点云距离掩盖错误的材料点身份或时间顺序。
4. **运动与相对几何分别计分**：坐标误差反映完整输运；同时间粒子间距离等反映相对几何。客观几何不等于所有坐标分量数值不变。固定实验室坐标系的重建优劣不能变成任意时变 observer 下客观性的证明；任意 observer 检验应单列。
5. **留出真正独立的内容**：先按原始流场和完整积分时间窗口拆分训练/验证/测试，再生成 primitive；检测积分区间和材料轨线复用。跨流场留出应按 physical family 分组，同一流场的重采样版本不能假装是全新流场。有限的独立流场数是限制，不能用更多相邻 seed 替代独立样本。
6. **沿用 Cylinder 时间政策**：新实验的初始物理时间至少为 7.5，不追溯更改历史实验；没有 IVD p95 分类目标，不人为调整 p95 为新任务服务。
7. **记录真实开销**：特征值、位置/尺度等公共信息和离散词表（如果以后采用）都计入表示用量；共享解码器大小、训练和推理成本另报。主问题先用连续 token；不因“tokenizer”一词就额外引入量化损失或离散词表。

## 当前建议与待讨论选择

优先建议 **A：可查询的局部流映射重建**。它直接检验一个 primitive token 是否足以表达局部材料运动，目标容易从现有速度场生成，评估也比类别标签更接近表示本身。B 更强调 token 供上下文模型使用的能力；C 更强调可组合性，但实现与解释难度更高。

三个候选可以互相启发，但当前不把它们擅自合并成已确定的 Task6。待用户选定主要问题后，再注册正式版本、冻结预算/划分/指标及基线，并设计 Ibex 实验。本轮只完成进展记录与方案讨论。
