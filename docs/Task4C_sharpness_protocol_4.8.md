# Ablation_Task4C_Sharpness_4.8

2026-09-13。保持4.5已选输入、模型、尺度一致性与学习率，比较普通AdamW与Sharpness-Aware Minimization（SAM，使用邻近权重处的损失梯度更新网络）。只读训练/验证；4.6已报告的10,000束测试、阈值和结果不变。本消融完成不代表两模型测试F1达到0.6。

## 方法和来源

依据[Foret等人的SAM论文](https://arxiv.org/abs/2010.01412)式2–3及[作者实现](https://github.com/google-research/sam/blob/main/sam_jax/training_utils/flax_training.py)的`dual_vector`与`get_sam_gradient`：在同一批数据计算梯度g，以e=ρg/max(||g||₂,1e−12)扰动全部参与计算的可训练参数，再计算w+e处的梯度；恢复原参数后执行一次更新，不对e求二阶导数。零梯度对应零扰动。

这里使用原任务的AdamW，不声称复现论文图像分类实验；权重衰减仍由AdamW解耦执行，不加入扰动方向。论文官方实现使用损失内L2及SGD/RMSProp，此差别明确保留。两次前向使用同一物理样本对、标签、dropout随机状态，随机状态最终仅前进一次。第一步梯度不裁剪，第二步梯度裁剪范数1后更新。原模型使用LayerNorm/GroupNorm，没有需要额外处理的BatchNorm运行统计。

候选ρ固定为0、0.05、0.1，0.05来自官方示例，0.1是有限的两倍半径对照；不继续追加半径。ρ=0也做两次前向/反向，保证计算次数相同，并核验其更新与单次普通AdamW一致。第二步异常时精确复制原权重恢复，避免使用减法造成舍入漂移。

## 固定设置

保持4.1物理多尺度数据和隔离：Channel/TBL各13,500训练、1,500验证、5,000测试；只逐字节复制4.4的训练/验证编码。FMT仍为每线161维局部特征＋72维有符号位置/单位切向频谱＋mask、原4.3逐线学习聚合模型88,514参数。Conv3D仍为四通道24³体素及原4.3网络219,602参数。模型输入只含几何及有效线mask。

固定4.5三种子验证已选配置：两方法学习率0.001、dropout0.15、weight decay0.001、label smoothing0.02；尺度一致性最大权重FMT10、Conv3D1，原五epoch升权规则。每个batch64中心视图＋同中心不同尺度64伙伴，单例不计一致性。每epoch13,500次中心抽样、27,000个监督视图、54,000次前向视图，两次前向不是新增独立训练数据。保持head均匀抽样、batch128、最多200epoch、学习率预热5epoch及余弦下降、35epoch早停；推理单束，不做尺度投票。

## 有限选择流程

种子96011运行三半径×两方法，共6次。每方法始终保留ρ=0对照，并在正半径中按验证F1、其次平均精确率选择一个；这两项均以96012/96013复核，共8次。最终报告各自三种子均值和标准差，不用测试选参数。与4.5跨版本比较包含新种子差异，主要结论来自本版本内同种子的ρ=0配对。

代码、训练和编排集中于`experiments/Task4C_Sharpness_4_8.py`，复用冻结4.5配对/损失和4.3模型，旧源码不改。配置`config/Ablation_Task4C_Sharpness_4.8.json`，提交脚本`ibex_bash/task4c_sharpness_4p8.sh`；每个Slurm进程记录到registry。没有final/test命令或自动测试分支，不把旧验证门槛重新作为主目标。

工程核验以内联命令执行，记录集中于`outputs/Verify_Task4C_SharpnessCode_4.8`，不新增一次性test/verify源码。检查零半径与原AdamW更新及随机状态一致、独立二次函数的扰动/梯度公式、异常恢复、真实pilot训练/选择及拒绝测试入口。模型权重只保留内存。
