版本：`Other_FMT_AnalysisWorkbench_1.2`。用户要求选中特征后用流程图说明其来源，并检查Hairpin形状贡献图为什么看不出支持正类的形状。保持1.1全部源数组、已选模型、预测和分组不变；只重建解释界面及可由原精确干预分数派生的显示数据，不训练或重新采样。

## 特征步骤图

每个141维特征均映射至：七线32点几何 → 整组质心/最大半径归一化 → 中心步进/中心坐标与切向/邻居相对变化 → 离散傅里叶变换 → 指定频率的实部、虚部、范数、实虚向量余弦或三重积 → 必要的六邻居均值或数值最大值 → 拼接数组位置 → 逐特征标准化。高亮当前路径，其他分支淡化；显示所选样本当前原特征值和标准化值。保留三个不同输入序列与两种FFT归一化规则，不把频域向量夹角说成物理邻居夹角。

## 正类支持修订

核查目标仍为m=logit(Hairpin)−logit(Non-hairpin)，干预分数Δ=m(原束)−m(局部拉直束)。Δ>0表示该原片段相对于这次拉直干预支持Hairpin；Δ<0表示相反。紫色端点连线是非物理诊断替代几何，不是积分得到的涡线。默认关闭替代线叠加，提供明确说明、原/改概率和分数。

原版用重叠窗口有符号平均给点上色，可能抵消正类支持；默认最强窗口按|Δ|排序会选中负值。新默认直接高亮每束最大的正Δ原始窗口，背景细灰线，不再平均成逐点贡献。可查看前三个正窗口，分别保存精确分数；重叠片段不是可相加的贡献。无正窗口时明确显示没有正支持，不能从负值取绝对值伪造。

单束页给出所有线×7窗口的精确有符号干预热图，可点击选择任意正/负片段；正类窗口表按Δ降序，反对窗口另行查看。可切换全部有符号窗口或原梯度敏感度，但显著标明梯度范数无正负方向。旧重叠平均图保留为历史诊断模式，不作为默认正类支持图。

形状干预同时影响弧长、切向及可能的整束归一化，不能解释成孤立曲率因果效应；单线局部干预也可能无法破坏多线冗余证据。可视化不保证所有束出现同一头部/腿部模式。
