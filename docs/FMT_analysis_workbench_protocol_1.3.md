# 分析工作台1.3：解释着色方法（2026-09-17）

版本`Other_FMT_AnalysisWorkbench_1.3`。用户指出“精确片段”“历史重叠片段”“梯度”等名称难懂，界面缺少直接解释。本次仅修改说明、显示和控件，不重新计算科学数据或替换模型。

## 每种模式的准确含义

| 新名称 | 旧名称 | 计算对象 | 颜色含义 |
|---|---|---|---|
| 拉直一段，看是否影响Hairpin（推荐） | 精确片段 | 保持两端和其他线不变，拉直8或9点组成的一段，比较原/改模型得分 | 原片段红色支持、蓝色抑制Hairpin；灰色是未高亮，不是无用 |
| 旧图：把多个片段结果平均到点上 | 历史重叠片段平均 | 对被多个片段改动的内部点取这些片段Δ的有符号平均 | 正红负蓝；平均会抵消，不是点的独立贡献 |
| 轻微移动点：查看敏感位置 | 梯度敏感度 | 原模型Hairpin得分对三维坐标的梯度范数 | 黄到红表示敏感度增大，无支持/反对符号 |
| 加噪16次：查看平均敏感位置 | 平均梯度敏感度 | 原16组加噪下梯度向量先平均、再取范数 | 黄到红表示平均梯度大小，不是稳定性或鲁棒性评分 |
| 只看线束形状 | 原始几何 | 原轨线几何 | 统一颜色，无分数含义 |

得分仍为`logit(Hairpin) − logit(Non-hairpin)`；拉直变化仍为原得分减改变后得分。源代码`FMT_Utils/Task4C_Saliency_1_1.py`的算法不变。

## 界面修改

选择器旁显示一句用途说明，图上方常驻“怎么测、颜色怎么读、解释限制”。可展开五种图对照表；不要求先阅读页面底部。概率显示百分数，概率差明确写为百分点；Δ明确为模型分数差，不是百分比。

只有局部拉直模式显示片段选择、紫色替代线、拉直后概率、窗口热图和片段表。其余模式隐藏这些不属于当前着色方法的结果；画廊标签也不再混入最大正Δ。切回推荐模式恢复原有片段交互。原始几何和模型概率始终保留；灰线不是零贡献标签。

浏览器核验发现当前打包Plotly的内置`YlOrRd`在旧梯度图中实际显示低值深红、高值浅黄。1.3改为显式指定由浅黄到深红的色带，保证高敏感度为深红；再次核对了色条0值端与高值端。这只改变颜色映射，不改变梯度数组。普通梯度和加噪平均梯度共用该修正。所有点着色仍按每束各自范围缩放，不能跨束比较颜色深浅。
