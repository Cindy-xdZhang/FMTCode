# Verify_Task6_PNNTrans_1.1 — pnn_trans 自编码器

2026-09-11，用户要求参考 Point-NN，逐时间步提取固定几何特征，再用注意力 Transformer 压缩并重建完整 primitive。此版只推进 Task6；Task7/8、旧 FMT/VAE 代码和指标保持冻结。方法级结果只记入 `docs/experiment_log.md`。

## 阅读依据与适配边界

论文：[Parameter is Not All You Need: Starting from Non-Parametric Networks for 3D Point Cloud Analysis, CVPR 2023](https://arxiv.org/html/2303.08134v2)。源码固定为 [Point-NN a85bfc365258a2c65a5f6ac289537b4d7a7cec0f](https://github.com/ZrrSkywalker/Point-NN/tree/a85bfc365258a2c65a5f6ac289537b4d7a7cec0f)，MIT 许可随代码保留于 `third_party/point_nn/LICENSE`。

原模型用固定三角函数编码三维坐标，以最远点采样、最近邻分组、相对位置加权和最大值加均值池化逐级提取形状特征，分类端另有带标签的记忆库。本实验仅借鉴空间编码操作，不使用其标签记忆库或分类评估流程，也不把 pnn_trans 称为原论文复现。

原 `models/point_nn.py` 用 `beta*x/alpha**(m/M)`，论文式(6)中两个字母的用途相反；本实现明确遵循代码命名。原默认1024点、4级、90邻居不能直接用于7点。原局部标准差跨整个调用批次计算；原 BatchNorm 在 eval 时使用未训练的单位统计量。本适配去除批次依赖及可训练的 BatchNorm affine 参数，确保固定空间模块确实有零个参数。

## 输入与空间编码

输入 `G[n,i,t,a]` 为第 n 个 primitive、第 i 条物质路径线、时间索引 t、空间轴 a 的坐标，形状 `[N,7,32,3]`。仍采用旧协议的 `(x-center(t0))/r`；`r` 为初始邻居半径。七条线的固定顺序为中心及三个轴的正负邻居。初始21个坐标恒定。

只用当前训练子集全部点，拟合一个三维位置均值 `mu` 和一个标量位置尺度 `s`。`q=(G-mu)/s`。这不逐时间步移动中心或缩放点云；整体漂移和邻居距离仍在输入中。解码端另保存训练集逐坐标均值及一个残差尺度，仅用于输出数值标准化，不能从这些常量还原某个输入样本。

每个时间步独立执行以下固定操作，没有时间差分和时间离散傅里叶变换：

1. 对每个坐标使用8个频率 `omega[m]=1/1000**(m/8)`，拼接 `sin(omega*q)` 和 `cos(omega*q)`，得到每点48维 `f_i`。
2. 保留全部7个点作为锚点，每个锚点使用全部7个邻居（含自身），无需对仅有7点再降采样。计算同一时刻 `q_j-q_i`、`f_j-f_i`，分别除以**该样本该时刻**49对差的标量标准差加 `1e-5`。标准差不跨样本或时间。
3. 拼接规范化的特征差与锚点 `f_i`，得到96维 `h_ij`。使用16个频率将规范化位置差编码为96维 `e_ij`，计算 `(h_ij+e_ij)*e_ij`（逐元素乘法）。
4. 对邻居 j 取最大值加均值，按原 eval BatchNorm 的固定单位尺度处理，再用 GELU 激活函数，得到每锚点96维。与原48维编码拼接，按7个锚点的固定身份排列为1008维时间步特征。

保留原始位置编码以及锚点身份，是为完整、有对应关系的轨迹重建所作的明确适配。仅把七点无序池化为一个向量，会删除物质线身份，不能不加说明地用于对应点重建。这里的空间编码使用坐标分量和非线性运算，本版不预先声称最终 token 具有任意时变刚体观察者下的客观性。

## 时间编码与解码

`32x1008 → 学习的1008→128投影 → 32个学习的时间位置编码 → 3层Transformer → 展平32x128 → 学习的4096→192压缩 → 全连接解码器 → 7x32x3`。

Transformer 每层4个注意力头、内部前馈宽度512，采用层归一化后计算注意力/前馈更新的残差结构（pre-norm）。三个层独立初始化。192维 latent 是整个 primitive 唯一输入相关的解码信息。解码器隐藏宽度512、3个两层残差块，最后预测651个非初始坐标，补回协议固定初始点。无解析逆变换、无PCA初始化、无原始几何跳接。最后一层零初始化，因此未训练输出为训练平均轨迹。

这是**确定性自编码器**，没有变分自编码器的随机后验和 KL 损失。用户本次要求自编码结构，本版先检验其几何压缩和重建能力；不能据此声称已验证生成建模能力。

`raw_trans` 主对照使用相同 `q`，每时刻直接输入21坐标，使用相同 Transformer、192维 latent、全连接解码器和训练配置。仅输入投影维数不同，分别报告参数量，不能声称两臂参数数量完全一致。历史4.1 Raw-VAE、5.1 Raw-VAE/FMT及独立192维主成分分析（PCA）结果保持原版本，单独引用。

## 冻结数据、训练和测试

复用经独立审计的3.1/4.1数据，九流场、每流场独立网络、32个完整采样时刻。训练规模256/1024/4096，1024为主设置；搜索种子94110，最终三个子集/优化种子94111/94112/94113。每流场validation/test/unseen_scale各12000。Cylinder播种区间仍为原始[0,15]中的[7.5,12]，一般流场为原始区间10%–80%，保证完整积分。训练、验证、测试源时间窗隔离；不重新挑选容易的场景或轨迹。

先验证源码数学操作、无参数前端、批次独立性、时间独立性、物质点身份、latent单一路径和实际拟合。随后九流场各用32个训练样本做2000步拟合检查，要求误差低于初值15%，且latent置零后误差至少增加10%。这仅是拟合检查，不代表泛化成功。

正式搜索为九流场×2候选×2方法，共36次训练，每次12000更新、batch128、前200步学习率预热，随后余弦衰减到初始10%，梯度范数裁剪1，每1000步评价完整validation。只在正训练步选择最低validation误差，最优状态仅存内存。几何损失为完整非初始点三维平方距离平均除以训练残差尺度平方。

| 候选 | 学习率 | Dropout（随机丢弃网络激活） | 权重衰减 |
|---|---:|---:|---:|
| c0 | 0.001 | 0 | 0.0001 |
| c1 | 0.0003 | 0.1 | 0.001 |

按九流场等权validation均值选择唯一pnn_trans候选，Raw使用同一候选。**只有选中候选的两臂在全部九流场validation误差均小于3，才允许提交最终测试训练批次**。否则完整汇报validation失败，不打开test，不自动改配置，也不继续提交大批最终作业。

通过后，九流场×3训练规模×3种子分别从随机权重重训两臂，共162模型。每个最终模型仍有validation<3门槛；失败保留且不访问其test。全模型均通过才计算完整test macro，不能通过删除失败流场得到更好的平均值。每个合格模型只评价一次test和unseen_scale，保存预测并独立复算误差。

主指标是 `sqrt(sum_{n,i,t=1..31} ||prediction-truth||^2 / (N*7*31))`，即沿用原单位的**三维位置 RMSE/r**，不是逐坐标均方根误差。另列端点和七线同时间点间距离。每流场先平均种子，再对九流场等权平均。已有test是已用benchmark，不是新的confirmation。
