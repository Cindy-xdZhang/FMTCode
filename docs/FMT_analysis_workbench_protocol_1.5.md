## 数据与模型

旧第三页使用4.14数据，测试头部实际覆盖Channel 55/74、TBL 46/58个实例。旧导出没有遗漏数据行；缺口来自原采样及整片候选区域多数归属规则，不能用扩大显示数量解决。

新数据以BottomDensity1.2为基础，每个GT新增10束测试、30束邻近训练，共1320/3960束；总量196960训练、3000验证、11320测试。132个GT均已通过正式几何与配额核验，原数据前缀与验证文件保持不变。新增中心在人工GT内部并满足头部几何条件；不依据模型预测选样本。

固定c156、seed96721、992386参数，使用原优化和验证选轮规则。此次是一份供交互查看的单种子预测，不是新的三种子方法比较。扩大后的测试集合类别比例发生变化，不能把整体F1变化解释成架构提升。

## 三个页面

第一、第二页逐文件继承1.4，哈希保持一致。形状解释页仍对应原p35模型；第三页使用本次重新训练的c156，顶部明确区分这两个来源。

第三页的测试视图包含全部11320束；训练视图只展示3960束新增头部训练样本。训练F1仍按完整196960束计算，页首和页脚说明展示子集与评价总体的区别。

默认进入“GT Head附近线簇＋Non-hairpin”模式，显示全部真实头部正类束及100束负类。按真实标签选择头部束，所以模型判为Non-hairpin的漏检仍显示。默认分析着色：TP表示正确识别Hairpin，FN表示漏检Hairpin，FP表示负类误判为Hairpin，TN表示正确识别负类。

逐GT表格各列的含义：

| 列 | 计算方式 |
|---|---|
| 可用头部束 | 当前集合中，中心属于该真实GT、满足头部夹角条件、标签为正类的全部束 |
| 其中新增 | 这些束中，本次追加的数量；测试每GT10，训练展示每GT30 |
| 实际显示 | 当前模式、区域、类别开关和显示数量筛选后真正画出的头部束数 |
| 正确识别 | 全部可用头部束中，c156的Hairpin概率至少0.5的数量 |
| 漏检 | 全部可用头部束中，c156的Hairpin概率低于0.5的数量 |

正确识别和漏检之和等于可用头部束数，不受显示数量影响。点击某个GT行，会切换到该GT区域并显示其全部头部束。表格按中心在原GT体单元中的实际归属计数；不把旧整片候选区域的标签归属误当成中心所在GT。点选详情分别显示中心GT与标签来源实例。
