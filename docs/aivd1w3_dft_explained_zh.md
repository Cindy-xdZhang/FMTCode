# aivd1w3_dft：从七条路径线到一个标量

本文对应2026-09-07核对的原始实现，核心文件为 `FMT_Utils/DFT_FMT_3D.py` 的 `pathline_velocity_gradient_scalar_sequences_3d` 和 `pathline_anchored_kinematic_dft_features_3d`；名称解析在 `FMT_Utils/Task12Data_3D.py::_anchored_recipe`。它解释现有代码，不把近似公式当作已验证的严格离散客观性。

2026-09-07术语纠正：此前把“同时间点差随旋转协变”和“不客观”混用，会错误地把客观性限于标量数值不变。**同一时刻、同一对物质点的相对位置是客观几何向量；客观向量在不同坐标基底下的分量按旋转矩阵变换。** 下文的 D*=QD 指分量表达改变，不指粒子相对几何改变。此修订只澄清表述，不修改任何冻结代码、图片标签或实验结果。

## 1. 输入是什么

一个 primitive 有七条同步采样的粒子路径线：一条中心线，以及从中心初始位置的+x、−x、+y、−y、+z、−z方向出发的六条邻居线。当前固定缓存每条线32个点，输入形状[N,7,32,3]，N是本次传入的primitive数。这六个方向指初始布点方向；随流动演化后，三对邻居不必仍平行于坐标轴。

这个配方本身不使用中心线的位置序列。中心线用于定义primitive和标签归属，但不是下面的特征输入。它也不读取真实速度、真实curl、IVD标签或p95阈值。所有量都从六条邻居路径线估计。

## 2. 同一时刻的三对邻居间距

对primitive n，在采样时刻k构造3×3矩阵

$$D_{n,k}=[x_{+x}(k)-x_{-x}(k),\ x_{+y}(k)-x_{-y}(k),\ x_{+z}(k)-x_{-z}(k)].$$

每列都是**同一时刻**两个物质粒子的相对位置向量，是客观几何量。参考系平移会在点差中消去；参考系旋转改变的是同一几何向量的坐标分量表达。采用x*=Qx+c的约定，这一正确的分量变换规律写作D*=QD，不能据此否定相对位置的客观性。三列各自的长度及它们之间的夹角不变，D*ᵀD*=DᵀD。客观向量允许分量按Q变换；客观标量才要求数值相同。

## 3. 对邻居间距随时间求导，估计空间速度梯度

物质粒子满足dx/dt=v(x,t)。因此一对邻居的间距导数满足

$$\dot d=v(x_+,t)-v(x_-,t)\approx (\nabla v)d.$$

这里要求邻居足够接近、速度场足够光滑，才能用一个局部梯度描述三对相对速度。有限邻居距离下它仍是近似，而不是直接读取原流场的精确梯度。三对一起写成Ddot≈(∇v)D，于是

$$\widehat L=\widehat{\dot D}D^+\approx\nabla v.$$

**这里的时间差分用于获得邻居的相对速度，乘伪逆则用空间间距估计空间梯度。不是对单条路径线连续做两次时间差分来求curl。** 第二次时间差分通常涉及加速度；curl需要速度在空间方向上的变化。

从代数上，Δt(x+−x−)=Δt x+−Δt x−。因此也可以等价地理解为“先沿各路径线估计速度，再在同一时间比较邻居速度”。用户关于“路径线差分估计速度，再估计curl”的理解在这个意义上是对的；需要明确的是后一步用的是**空间间距和相对速度**，以及求出curl后还要减去平均涡量。先做空间差再做时间差，本身并不会自动消除时变旋转影响。

当前实际调用没有传sample_times，把相邻采样序号之差当作1。第一个点用D1−D0；内部点用(D[k+1]−D[k−1])/2；最后一个点用单侧差分。伪逆相对奇异值阈值为1e−6。接近共面/共线的邻居交叉会导致病态、截断或误差放大。

若物理采样间隔严格一致为h，这种导数大致是物理导数的h倍。若间隔不均匀，就不能统一解释成只差一个比例。现有固定缓存从49个积分点按整数索引选32点，可能出现1步、2步交替的间隔。原配方没有纠正它；移植实验保留这一事实，避免同时更换算法。

例如按代码中的round(48×linspace(0,1,32))选点，开头四个原始积分索引是0、2、3、5。如果积分步长为h，物理时刻差就是2h、h、2h；原配方仍按采样序号间隔1计算。这是“几何IVD估计”与物理单位下IVD之间的另一层区别。

## 4. 从空间梯度提取涡量，再减去样本平均涡量

采用L[i,j]=∂v_i/∂x_j约定，

$$\widehat\omega=(\widehat L_{32}-\widehat L_{23},\ \widehat L_{13}-\widehat L_{31},\ \widehat L_{21}-\widehat L_{12}).$$

再计算

$$\bar\omega_k=\frac1N\sum_n\widehat\omega_{n,k},\qquad s_{n,k}=\|\widehat\omega_{n,k}-\bar\omega_k\|_2.$$

s是**瞬时涡量偏差（instantaneous vorticity deviation，IVD）的估计标量**。先对涡量向量求平均并相减，最后取模；不是先取每条涡量的模再减平均模。较大的s表示该处的估计旋转与样本整体平均旋转差异较大，不等于自动满足真实p95涡标签。

这里的平均是同一个输入时间片中全部保留primitive的算术平均，**不是原始全空间网格的物理体积平均**，也不是单条路径线自己的时间平均。采样范围、有效粒子和权重都会影响它。相同物理时间、相同样本集合是跨observer比较的条件。在N=1时它必为零。先在全时间片上计算特征，再分VAE minibatch；若每个minibatch重算平均，已经换了表示。

函数还计算应变强度、绝对散度和一个Q-like量，但本配方只取第0通道s，不使用其余三个通道。

## 5. 名字怎样解析，傅里叶模块实际做了什么

| 字段 | 实际作用 |
|---|---|
| a | anchored kinematic特征函数家族的入口；本名称的_dft后缀关闭额外统计量 |
| ivd | 只保留涡量偏差模长s这个通道 |
| 1 | 只保留一个傅里叶频率格点，即零频 |
| w3 | 使用最前面三个标量采样值 |
| _dft | 只输出离散傅里叶变换（discrete Fourier transform，DFT）部分，无first/mean/std等附加统计量 |

DFT零频的指数因子都是1，默认实现没有除以窗口长度，因此

$$f_n=s_{n,0}+s_{n,1}+s_{n,2}.$$

**最终每个primitive只有一个实数；没有非零频率、周期、相位或旋转方向信息，也不能从这个特征恢复三个时刻的变化次序。** 例如[1,2,3]与[3,1,2]都输出6。在固定训练标准化下，和与均值通常只差一个会被标准化抵消的正比例，但原始函数严格输出和。它不是按物理时间求积的Lagrangian-averaged vorticity deviation（沿物质轨迹积累的涡量偏差）。

注意先计算完整序列的导数和s，再截取前三个s。因此第三个标量s2用到(D3−D1)/2，**实际依赖最前面四帧坐标**（当原序列长度至少4），不是只读前三帧坐标。第四帧之后不影响该配方的最终输出。

## 6. 客观性为何不能只看有没有时间差分

在时变刚体坐标变换x*=Q(t)x+c(t)下，同一组物质邻居满足D*=QD。连续求导且D满秩时，

$$L^*=QLQ^T+\dot Q Q^T.$$

相机旋转引入的最后一项在同一物理时刻对所有primitive相同。相应地，涡量变换可写成ω*=Qω+b(t)。用同一批样本和相同权重扣除平均后，b消失：

$$\omega_n^*-\bar\omega^*=Q(\omega_n-\bar\omega),\qquad \|\omega_n^*-\bar\omega^*\|=\|\omega_n-\bar\omega\|.$$

这说明中间量含observer项，不代表最终标量不客观；要检查observer项是否在完整运算中抵消。上述结论需要满秩、同步且共享的时间、对应的物质邻居以及一致的平均范围。若D秩亏，Ddot D^+的推导还会带入随primitive变化的投影，不能直接套用满秩公式。

离散实现则不同：对Q[k]D[k]做有限差分，不满足精确的连续乘积求导法则。动态Q产生的残差可能随primitive变化，因此减去平均并不能保证完全消除。

可以直接看第一个点的一侧差分。设ΔQ=Q[k+1]−Q[k]、采样间隔为h、D[k]可逆，则精确的离散恒等式是

$$\widehat L_n^*=Q_k\widehat L_nQ_k^T+\frac{\Delta Q}{h}Q_k^T+\Delta Q\,\widehat L_nQ_k^T.$$

中间一项对所有primitive相同，可以在平均扣除时消去；**最后一项还乘着每个primitive自己的梯度**，一般不能一起消去。连续极限下ΔQ趋于零；固定旋转时ΔQ=0。这比“用了时间差分所以不客观”更准确地指出了离散问题的位置。

| 变换 | 当前固定样本上下文下的判断 |
|---|---|
| 任意时变平移 | D在每个采样时刻不变，后续结果在精确算术下不变 |
| 固定旋转 | 时间差分与旋转可交换，理论上标量不变，浮点和伪逆阈值附近误差除外 |
| 时变旋转 | 连续满秩公式有客观性依据；现有有限差分算法没有严格不变性保证 |

同时间的点差是客观向量；“分量按Q变换”不等于“不客观”。但把不同时刻、不同基底下的分量直接送进普通傅里叶变换，不自动继承客观性。普通时间导数包含基底运动项，需要说明其如何抵消，或者先构造客观标量再分析其时间变化。连续涡量偏差的抵消机制正是一个例子。

一个连续理想例子：某时刻三个样本的涡量都沿z方向，分量分别为[0,2,4]，平均为2，偏差模长为[2,0,2]。若参考系旋转带来的统一涡量项是−2，它们变成[−2,0,2]，平均变为0，偏差模长仍为[2,0,2]。这说明绝对涡量变了，但相对样本平均的旋转偏差可以保持。这个例子解释抵消机制，不代表有限差分代码已严格满足连续公式。

## 8. 梯度到最终标量的逐项展开

以下n是primitive编号，k是同步采样序号，L是每条路径线的采样点数；当前常用L=32。代码数组D为[N,L,3,3]，矩阵的每一列是一对邻居的相对位置分量，列编号随同一对物质粒子保留。

### 8.1 为什么间距导数能估计空间梯度

对每对邻居d=x+−x−，在一个给定参考系中，物质轨迹满足dx/dt=v，故ḋ=v(x+,t)−v(x−,t)。在三对邻居所处的局部范围用同一个仿射速度模型v(x)≈b+A x，则三对速度差满足ḋ_j≈A d_j，合写为Ḋ≈AD。常量b消失。这里A的第i行第j列是速度第i分量对空间第j坐标的导数，单位为1/time；并不是加速度。

代码没有传sample_times，因此实际使用采样序号导数B：

$$B_{n,0}=D_{n,1}-D_{n,0},\quad B_{n,1}=\tfrac12(D_{n,2}-D_{n,0}),\quad B_{n,2}=\tfrac12(D_{n,3}-D_{n,1}).$$

这些是最后保留的三个标量所需要的全部导数项。每个时刻估计A=B D⁺：满秩时就是B D⁻¹；非满秩时是最小化||AD−B||_F的最小范数解。不是将两个矩阵逐元素相除。

伪逆采用奇异值分解D=UΣVᵀ，对保留的奇异值σ取1/σ，得到D⁺=VΣ⁺Uᵀ。`torch.linalg.pinv(D, rtol=1e-6)`把低于最大奇异值的1e-6倍的奇异方向截断，避免直接除以近零数，但也可能丢失该方向的梯度信息。

```python
derivative[:, 0] = pair_vectors[:, 1] - pair_vectors[:, 0]
derivative[:, -1] = pair_vectors[:, -1] - pair_vectors[:, -2]
derivative[:, 1:-1] = 0.5 * (pair_vectors[:, 2:] - pair_vectors[:, :-2])
inverse = torch.linalg.pinv(pair_vectors, rtol=1e-6)
gradient = derivative @ inverse
```

### 8.2 curl具体取哪些元素

设gradient矩阵为A，行对应速度分量，列对应空间方向，则curl(v)的三个分量为：

$$\omega_x=\partial_y v_z-\partial_z v_y=A_{zy}-A_{yz},$$
$$\omega_y=\partial_z v_x-\partial_x v_z=A_{xz}-A_{zx},$$
$$\omega_z=\partial_x v_y-\partial_y v_x=A_{yx}-A_{xy}.$$

代码0-based索引为：

```python
vorticity = torch.stack((
    gradient[..., 2, 1] - gradient[..., 1, 2],
    gradient[..., 0, 2] - gradient[..., 2, 0],
    gradient[..., 1, 0] - gradient[..., 0, 1],
), dim=-1)  # [N,L,3]
```

这是对已有梯度矩阵的反对称元素取差，没有第二次时间求导，也没有再读取速度场。涡量是curl，刚体转动时其值为角速度向量的两倍；代码没有额外除以2。

### 8.3 同时间减均值的具体维度和原因

```python
mean_vorticity = vorticity.mean(dim=0, keepdim=True)  # [1,L,3]
deviation = vorticity - mean_vorticity              # [N,L,3]
scalar = torch.linalg.vector_norm(deviation, dim=-1) # [N,L]
```

dim=0只对primitive编号求平均。每个k都有自己的三维平均涡量，绝不是沿时间平均。先减向量再取欧氏模长：s=sqrt((ωx−meanωx)²+(ωy−meanωy)²+(ωz−meanωz)²)。所有N个输入primitive贡献相等权重；当前调用并未对原始网格进行全域体积积分，也不读取真实IVD监督。

为什么这样构造？对连续导数及满秩D，在同一个刚体观察者下，A*=QAQᵀ+Q̇Qᵀ。Q̇Qᵀ是反对称矩阵；设它作用在向量r上等于q×r，对应的附加curl就是2q。因此ω*=Qω+2q；同时间平均也变为meanω*=Q meanω+2q，两者相减后共同的观察者旋转项消失，再取模长便得到同一个标量。符号取决于使用的坐标变换方向，这里与x*=Qx+c一致。

这一步会保留相对于所选样本平均旋转的偏离。若所有样本的涡量都相同，全部s都为0，即使它们共同有很强的刚体旋转；它不是绝对涡量强度。样本集合变化也可能改变s，所以跨observer必须用同一批物质primitive和相同权重。

### 8.4 前三个标量和零频

`channels=(0,)`只选择上述s；其他应变、散度、Q-like通道虽在共享函数中计算，但不进入本配方输出。`window=3`在完整序列算好之后取s0、s1、s2，而不是涡量的x/y/z分量。由于s2的导数用D3，L>=4时需要前四帧坐标。

对每个primitive的三点序列执行实输入离散傅里叶变换，长度为3：

$$S_n(j)=\sum_{k=0}^{2}s_{n,k}\exp(-2\pi i jk/3).$$

实输入变换会产生j=0与j=1两个独立频率格点，但`num_freq=1`切片只留下第0格点。此时指数全为1、虚部为0，PyTorch默认正向不归一化，所以输出f=s0+s1+s2，形状[N,1]。没有除以3，没有取功率或平方，没有额外取频谱模，没有保留任何非零频率。

```python
series = series[..., [0]][:, :3]          # [N,3,1]
spectrum = torch.fft.rfft(series, dim=1)[:, :1]  # [N,1,1]
real = spectrum.real.transpose(1, 2).flatten(1) # [N,1]
imag = spectrum.imag[:, 1:].transpose(1, 2).flatten(1) # [N,0]
features = torch.cat((real, imag), dim=1)  # [N,1]
```

`anchor_names=()`关闭附加时间统计；`log_compress=False`不做log1p。这一配方虽调用傅里叶模块，实际只汇总前三个s的大小，不能区分相同总和下的时间顺序、振荡频率或相位。

## 9. 全轨线版本 aivd1w3_dft_longtime

2026-09-07 用户要求保留原方法，另建全轨线窗口。新方法复用上文每一步，只将 `window=3` 改为 `window=None`。设输入有 L 个同步采样点，s[n,k] 是第 n 个 primitive 在第 k 个采样时刻的估计涡量偏差模长，则两个输出分别为：

$$f_{\mathrm{short},n}=s_{n,0}+s_{n,1}+s_{n,2},\qquad f_{\mathrm{long},n}=\sum_{k=0}^{L-1}s_{n,k}.$$

本轮 L=32，因此长版本使用32个标量，包括轨线后半段。两者都输出1维，均为未归一化的傅里叶零频。没有把32个标量直接拼成32维特征，没有增加非零频率，也没有重新积分更长轨线。名称中的 `w3` 保留以标识其原始配方；`_longtime` 明确覆盖其窗口设置。

原共享函数原本就计算完整序列，再在傅里叶变换前截取前三点；新增代码取消这一次截取。长版本的内部采样点采用中心差分，首末采样点采用单边差分，与原共享函数一致。仍按采样序号求导，没有新增物理时间间隔除数或时间积分权重，因此输出是沿采样序列的几何统计，不应直接写成经过物理时间积分的涡量偏差。

```python
if str(name) == "aivd1w3_dft_longtime":
    return {**_anchored_recipe("aivd1w3_dft"), "window": None}
```

Task5允许每条primitive采用不同的积分尺度。同一采样序号不一定对应同一物理时间，故本轮短、长两个分支都先按完全相同的物理采样时间序列分组，再在组内按上文计算同时间平均涡量。不同空间邻居距离可以共享同一时间组；不同物理时间序列不能混在一起求这个均值。此分组只使用轨线时间，不使用类别标签。

实验登记为 `Verify_AIVDLongtime_1.1`，覆盖Task1、Task2、Task3、Task5，各10个3D数据条目、5个随机种子。具体划分与训练预算见 `config/Verify_AIVDLongtime_1.1.json`；协议见 `Verify_experiments.md`，性能结论及证据只记在 `experiment_log.md`。原配方、原实验指标保持不变。
