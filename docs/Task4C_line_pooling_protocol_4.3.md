# mainExp_Task4C_LinePooling_4.3

2026-09-13，继续用户指定的两方法三种子合并测试Hairpin F1均值≥0.6目标。4.1和4.2冻结。4.2首轮最优验证F1约0.387/0.426，多种子复核尚在进行，不能声称达标。

## 固定数据与问题

全部物理样本、头区标签、尺度、空间分区和GT实例隔离直接继承4.1，parent config SHA256 `0c06c0530dcda7da82573a562e26c4932fb3331476347f7d3ba7aa6d8cc5cb99`。每流场13,500拟合、1,500验证、5,000测试；训练12、验证4、测试6个不同尺度元组，真实RK45多尺度几何不再修改。
不使用4.2合成增强，每个候选都用同一27,000原始训练样本，每epoch相同步数。测试几何/标签/顺序不变，仍在两方法三种子验证均≥0.6后才编码/评估。目标不是给验证集挑一个达到0.6的阈值，也不通过重新标注或减少测试难度达标。

当前固定聚合先分别统计每个频率系数，再学习判别；逐线频率之间的联合关系可能因此丢失。这是待验证假设，不是已证实的失败原因。参考[Deep Sets原论文](https://proceedings.neurips.cc/paper/2017/file/f22e4747da1aa27e363d86d40ff442fe-Paper.pdf)中先共享映射、再对集合聚合的形式；这里使用带有效线掩码的均值/最大值组合，不声称完整复现其所有网络。

## 编码器与网络版本

| 版本 | 无训练编码与网络 | 参数量 | 结果 |
|---|---|---:|---|
| 4.2 reference FMT | 固定610维统计，原4.2线性分类器 | 198,466 | 本轮重跑待定 |
| 4.3 per-line FMT | 每线161维冻结局部FMT＋72维坐标/单位切向有符号6频；共享233→128→128映射后mask mean/max，256→128→64→2 | 88,514 | 待定 |
| 4.2 reference Conv3D | 原4×24³输入，8/16/32通道、原线性头 | 101,194 | 本轮重跑待定 |
| 4.3 wider Conv3D | 同输入、卷积/池化拓扑，通道16/32/64，512→256→64→2 | 219,602 | 待定 |

FMT输出每束最多27×233；缓存最后一列234是有效线mask，不是额外物理特征。无训练编码器不变，新增的是下游共享神经映射。逐线集合能恢复4.2全部610维统计，对照和新模型均从同一缓存读取。统计对照使用原train-only signed-log/均值方差/±8截断；新模型在训练有效线层面拟合这些统计，padding不参与统计/聚合。网络聚合对token顺序不变；六近邻距离恰好相同时仍沿用冻结编码器按原线索引稳定排序，不声称重新构图在平距边界也严格不变。
Conv3D的体素化、坐标、切向和分辨率不变。两个方法参数量不同；同一种方法内，参数规模与标准化位置也有变化，结论应描述完整版本，不能归因于唯一因素。结果必须报告匹配学习率/正则化的配对候选，不只报告各自最优。

## 预先固定搜索

两组结构（reference/new）×学习率{3e−4,1e−3}×正则化{dropout0.15/weight decay1e−3, dropout0.4/weight decay1e−2}，共8候选×2方法。所有候选普通两类线性头、标签平滑0.02；不继续余弦间隔搜索。
head-uniform/view-uniform抽样、按训练抽样分布计算类权重、AdamW、batch128、200epoch、预热5epoch和余弦学习率最低1e−6、梯度范数上限1、35epoch早停均继承4.2。
seed95011搜索，各方法前两候选以95012/95013复核，以验证F1均值选择、平局按平均精确率。两个方法通过验证门槛后，以95111/95112/95113重训并评估固定10,000测试primitive。阈值和epoch只由验证选择；测试仍属于已用空间benchmark上的新尺度视图，不是独立物理快照。记录分流场、尺度和头区聚合指标；不保存模型权重。

## 工程与部署

入口`experiments/Task4C_LinePooling_4_3.py`；编码器/模型`FMT_Utils/Task4C_LinePooling_4_3.py`；配置`config/mainExp_Task4C_LinePooling_4.3.json`；作业脚本`ibex_bash/task4c_line_pooling_4p3.sh`。
独立内联核验覆盖：610维恢复、有效线掩码、分类器换序不变、四网络反向传播、真实两流场训练/验证缓存及四个两epoch训练流程、预测复算、测试编码不存在。证据`outputs/Verify_Task4C_LinePoolingCode_4.3/checks.json`，不保留临时测试源码。
首次本地等价断言出现5.7791误差，后续相同输入12次重复以及两流场240个训练样本未复现；原因尚未确定，不写成已修复bug。后续成功检查的最大恢复误差1.49e−8、聚合换序误差3.73e−8。正式编码每个分区首批32样本必须与原4.2编码器allclose核对（绝对1e−5、相对1e−6），失败即停止，不能跳过核验后训练。
