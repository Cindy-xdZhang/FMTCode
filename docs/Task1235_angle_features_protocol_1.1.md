# Task1/2/3/5 同时间夹角特征实验 1.1

2026-09-14 用户要求开发 `fmt_v5` 和 `fmt_objective_ntod_v2`，在进入傅里叶变换前加入每个时刻以中心为顶点的邻居夹角，并在 Ibex 测试 Task1/2/3/5。本次只重新推进这两个指定扩展，不恢复 Task6/7/8 或混合专家探索。方法结论只追加到 `experiment_log.md`。

## 方法与冻结对照

实验版本：`Verify_Task1235_AngleFeatures_1.1`。配置：`config/Verify_Task1235_AngleFeatures_1.1.json`。

| 方法 | 版本与代码 | 六频率原始输出维数 | 变化 |
|---|---|---:|---|
| 原始 FMT | 冻结 `DFT_FMT_3D.py::pathline_dft_features_3d` | 161 | 原中心差分、邻居相对向量时间差分、排序与手性描述量；函数默认scale100/weight0.5，实验缓存原为scale1/weight1 |
| fmt_v5 | 5.1；`FMT_Utils/fmt_v5.py` | 326 | 原161维保持，加165维同时间夹角傅里叶 |
| 距离版 nTDO v2 | 冻结2.1；`FMT_Utils/objective_fmt_nTDO_v2.py` | 231 | 全部21个同时间欧氏距离 |
| fmt_objective_ntod_v2 | 2.2；`FMT_Utils/fmt_objective_ntod_v2.py` | 396 | 原231维保持，加同一165维夹角分支 |

用户给出的第二个新名称与旧 `objective_fmt_nTDO_v2` 接近，因此新实现放在不同文件，方法修订号为2.2；旧文件及结果保持。输入为 `[N,7,L,3]`，line0是中心，其余六条为固定材料邻居。没有新增可训练编码器参数。

在每个存储时刻 t，令 d_i(t)=x_i(t)-x_0(t)，u_i=d_i/||d_i||。15个无序邻居对 i<j 的夹角为

`theta_ij(t) = atan2(||u_i(t) cross u_j(t)||, u_i(t) dot u_j(t))`。

角度范围[0,pi]，单位弧度；用float64计算几何和角度频谱，拼接时转换到原特征精度。按固定邻居编号排列，保留实系数频率0..5和虚系数频率1..5，因此15×11=165维。无时间差分、初始值相减、角度排序、幅度代替复系数或新权重。中心与邻居重合时夹角未定义，直接报错，不按方法丢弃样本。傅里叶轴沿原存储样本序号；旧采样的时间间隔性质保持，不宣称物理Hz频谱。

同时间相对位置是客观向量，距离与夹角是客观标量。距离+夹角编码器在材料身份与采样时刻对应时输出不变；原FMT分支以及监督模型中的Raw坐标输入仍需分别判断，不能把Raw+客观编码器的整体网络称为客观。全部点对距离已能通过余弦定理确定这些角度，本实验检验显式非线性角度表示的作用，不把它称为新增独立几何信息。
