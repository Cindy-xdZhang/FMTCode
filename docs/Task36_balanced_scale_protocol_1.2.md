# Task3＋Task6：修正任务平衡、扩大数据并进行最终测试，1.2

实验 `Verify_Task36_BalancedScale_1.2`，2026-09-12。用户要求进行最终测试，并在 FMT＋几何共享门控表现不足时扩大训练集，争取最好性能。本版本把 `joint_shared_gate`（两个任务共用同一个门控和同一个 192 维 token）作为主要研究对象；`joint_task_gates`（共享专家但两个独立门控）继续作为重要对照。不得将两种结构混称。

1.1 科学代码、配置、停止条件和所有开发结果原样保留。1.2 修正训练损失和选模规则，并预先增加数据量；不能把版本间结果差异全部归因于数据量。方法结论只追加 `docs/experiment_log.md`。

## 数据

- 九流场，每个网络只训练一个流场；继续使用冻结 3.1 源 primitive 和原 train/validation/test/unseen-scale 时间块、七线各 32 点、尺度与几何归一化。
- 两档训练集：3072 和 9216，后者三倍。使用冻结 4.1 `subset_order` 对同一个原训练源继续取前缀；逐个核对旧 4096 个索引和几何，保证 3072 档完全相同，9216 档包含旧样本。新增样本不来自 validation/test，不按标签或模型误差选择。
- 开发种子 94110；最终种子 94111、94112、94113。每档样本量、每个种子、每个流场，全部方法共享数据索引。
- 训练集扩张的决定已经由 1.1 验证结果和本次用户授权支持，两个档位在任何最终测试结果产生前冻结，不根据 test 决定保留哪档。两档结果都报告。
- Cylinder 播种时刻保持原 [7.5,12]；其他流场保持原时段 10%–80%，仍保证完整积分。源文件/manifest/配置的 SHA256、大小与 mtime 继续核对。
- 分类标签使用与 1.1 相同的中心种子物理位置和起始时刻 IVD、整场 p95 算子。把同一源时间的多个训练种子合批计算，减少重复读取；重新计算的旧训练前缀标签必须逐个等于 1.1，原 validation 标签逐字节复用。最终标签仅在开发选模冻结后生成。
- 标签、IVD、物理播种位置和时间不进入网络。联合模型包含 IVD 分类监督，不是纯自监督重建。

## 模型、损失与选模

架构及原 161 维 FMT 配方完全沿用 1.1。A 为冻结 FMT 后的可训练全连接专家，B 为原几何的可训练全连接专家；专家输出各 192 维，宽 512、3 块，解码器宽 768、4 块。没有逆傅里叶变换或几何旁路。共享门控把 A/B 加权成同一 192 维 token，分别接分类头与重建头；独立门控对照具有两个任务 token，共享专家对为 384 维。

1.1 用训练几何方差归一化重建损失，并按其与分类交叉熵之和选模。在 Re6400，方差约 3549 r²，导致 6.66 r 的误差只贡献约 0.0125 的评分。1.2 不再用该方差缩小重建损失：

`L = lambda * L_class + mean(||predicted_point - target_point||²)`

坐标已按每个 primitive 的邻居半径 r 归一化，第二项因此直接使用 r² 单位。`L_class` 仍是依据训练正类比例计算的类别平衡二分类交叉熵，除以 log(2)。两个固定候选 `lambda=1,4`；六个联合方法各自搜索这两个候选，两个单任务各仅训练 lambda=1，避免重复无关的多任务权重搜索。训练初始化仍保持两分支门控各 0.5，不强制专家分工。

所有方法、两个数据档位均为 72000 次更新、batch=128、AdamW、lr=0.0003、weight decay=0.001、dropout=0.1、3000 次预热、余弦学习率与梯度裁剪 1。每档位每个方法训练预算一致。9216 档在相同更新数下遍历次数为 3072 档的三分之一，不能宣称保持了相同 epoch 数。训练几何统计只来自该档位的训练样本，不能用 9216 样本初始化 3072 档。

**选同一个模型状态时，使用真实任务指标：**

`S = (1 - validation Average Precision) + validation RMSE/r`

Average Precision（AP，平均精确率）衡量涡类别的排序质量；重建 RMSE 是七线后 31 个时刻三维点距离误差的均方根。两个单任务分别只使用自己的那项。每 3000 次更新评估完整验证集，取正更新次数中 S 最低的同一个模型；不拼接两个不同 epoch。分类概率阈值仍在确定模型后只按验证 F1 选择。

超参数候选对每个“方法＋训练样本量”按九流场验证 S 的等权平均选择，因此同一方法同一档位的 lambda 跨流场不变。全部八种方法都参加最终测试，不只保留验证集赢家。AP 与 RMSE 最终分别报告；S 仅用于预先定义的选模，不用一个合成排名掩盖某项退步。

## 八组对照

| 标识 | 具体结构 | 与主方法的关系 |
|---|---|---|
| joint_shared_gate | FMT＋几何，两个任务共用门控及 192 维 token | 用户本轮指定主方法 |
| joint_task_gates | FMT＋几何，两个任务使用独立门控 | 验证任务专用路由的价值 |
| joint_raw_task_gates | 两个几何专家，两个独立门控 | 与对应双门控 FMT 结构等参数输入对照 |
| joint_raw_shared_gate | 两个几何专家，共用一个门控及 192 维 token | 与主方法相同初始化、参数量、路由和输出头，严格控制 FMT 输入 |
| joint_fixed_routes | 分类固定走 FMT，重建固定走几何 | 比较学习路由与固定分工 |
| joint_geometry_only | 单几何专家同时服务两个任务 | 比较融合与单个几何专家 |
| single_task3 | FMT＋几何，只训练分类 | 分类单任务基线 |
| single_task6 | FMT＋几何，只训练重建 | 重建单任务基线 |

共享门控必须优先与 `joint_raw_shared_gate` 比较 FMT 输入的作用；双独立门控 FMT 则与 `joint_raw_task_gates` 比较。两种路由均有严格输入对照，不将路由和输入的差别混为一项收益。

## 最终测试与失败保留

共 252 个开发模型、432 个最终模型（9 流场×2 档×3 种子×8 方法）。开发结束冻结 selection 后，生成 test 与 unseen-scale 标签，执行最终训练、预测、独立指标复算和汇总。整条链一次提交到 Ibex，最终数组提前登记并依赖开发与标签完成，不再依赖一个额外的条件提交程序。

本次用户明确要求进行最终测试，1.2 的执行规则变更为：**有限但 RMSE≥3 的模型标记为工程失败，仍进行测试并保留结果；不因此阻止其他模型，也不从平均值中静默排除。** 阈值仍为 3，不声称这些模型合格。非有限数值、数据错误或完整性检查失败仍终止对应进程，保留失败记录；缺模型/种子不得生成伪完整均值。1.1 的 `gate_passed=false` 和未启动最终测试的历史保持不变。

是否“最好”须看测试集 AP 与重建误差分别同全部对照比较，并列出每流场及种子差异；若只改善某个任务，应明确称作任务间取舍。不预先保证扩大数据一定使共享门控胜出。若仍需扩大数据或调整结构，应新建版本、仅由 train/validation 决定，并说明这里的 test 是已经使用过的 benchmark。
