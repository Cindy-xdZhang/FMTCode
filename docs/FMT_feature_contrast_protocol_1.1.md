# FMT 特征差异与多页分析工具 1.1

版本：`Other_FMT_FeatureContrast_1.1`；统一入口：`Other_FMT_AnalysisWorkbench_1.1`。用户要求解释 Cylinder 等流场的 FMT 二类聚类差异，并把该工具与 Hairpin 线束显著性工具置于一个 HTML 入口的不同页面。

## 数据与固定方法

首个实例读取用户现有 Cylinder3D / halfcylinderRe160 的直接特征 bundle，2160 个有效七线 primitive，32 点/线，物理时间 7.700000286–11.399996758。该输入为用户交互积分保存的数据，符合原模拟 [0,15] 的后半段要求；不是历史 Task1 的 t=10.5 缓存，也不是弃用的 Task2 VAE 结果。

采用当前 p35/n0_k06：中心步进傅里叶描述23维、坐标/单位切向方向频谱72维、六邻居相对变化傅里叶描述的逐特征均值23维及数值最大值23维。整组质心/最大半径归一化，邻居倍率1，6个频率。输入无速度梯度、curl、IVD估计或人工标签；不接VAE。所有141维给出数组位置、几何序列、频率及计算公式；频率指采样序号的离散傅里叶频率，不标成物理Hz。

读取原完整2160样本拟合的逐特征均值/标准差并核验；不在显示子集上重新拟合。KMeans在完整141维标准化特征上做二分类，不在二维投影上聚类。固定seed7068、20次初始化、max_iter300、tol1e-8。簇A/B按最小样本ID固定名称，不用标签或中心/边缘位置命名。主成分分析仅用于二维显示。

## 差异解释

设标准化特征为 z，两个簇的均值为 μA、μB。逐维差异 δj=μBj−μAj；排序依据 δj²，所占比例为 δj²/Σδ²。这是两簇中心平方距离的精确分解，不称独立特征因果重要性。相关维度可能重复表达同一形态。提供两簇原值及标准化值分布、全向量均值曲线、逐样本热图、维度组总和与每维平均，避免把大组天然较高的总和解释为独立贡献。

选中样本的逐维分簇依据为 (zj−μBj)²−(zj−μAj)²：正值支持A，负值支持B。总和严格等于到两中心的平方距离差。此计算固定既有簇中心；不是删特征后重聚类，也不是神经网络分类归因。

三维图显示真实物理坐标，可按簇或当前特征着色，并点击轨线联动向量和七线primitive。轨线整条使用其primitive特征值，不把整条着色伪称局部片段归因。显示筛选不改变聚类、标准化或排序计算人口。两簇不自动解释为涡/非涡；以原始几何供研究者观察。无需IVD标签、F1或其他质量指标。

## 使用

运行 `./start_fmt_analysis.ps1`，打开终端给出的本机地址。统一入口是`outputs/Other_FMT_AnalysisWorkbench_1.1/index.html`；保留两个相邻输出目录后也可本地离线打开，不依赖外部脚本或服务。

重新生成：`python -m experiments.Build_FMT_FeatureContrast_1_1 --config config/Other_FMT_FeatureContrast_1.1.json`。需要Python的numpy、scikit-learn、torch、plotly；本机已存在于相邻可视化项目的`.venv/Scripts/python.exe`，无需安装。更换同规范的141维p35 bundle时复制配置并修改`feature_bundle`与独立`output`目录即可；特征名称、源几何哈希、标准化和编码均自动检查。不支持把其他维数或PCA后的坐标伪装成141维p35。

独立核验：`python -m experiments.Audit_FMT_FeatureContrast_1_1`。原float32编码重算与缓存逐元素一致；另用NumPy逐维公式与PyTorch float64相互检查，最大差3.94e-13以内。float64与原float32在近直线的余弦/三重积比值上有最高约9.14e-5差异；这属于低幅度频率向量的浮点误差放大，不替换原特征或分组。最初把独立FFT后端比较设为统一5e-6绝对容差会在这些比值失败；修订为双精度公式核对，同时保留float32误差报告。所有展示值、几何块及逐维距离解释由导出数组再次核验。
