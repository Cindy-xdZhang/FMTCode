## 编码与假设

新方法名`vector_fmt6`。输入仍为可见七条轨线，每线32点。相对初始中心坐标用初始半径归一化；中心线沿时间做31个增量，六条邻居先减同时间中心位置，再做31个时间增量。各三维增量序列做离散傅里叶变换，沿用原配方的六个频率，不搜索更多频率。保留全部向量实部、非零频率虚部和邻居身份，不取模长、不做旋转不变量、不排序邻居。

总维数`7*3*(6+5)=231`，float32共924字节；Raw为672维/2688字节，原FMT为161维/644字节。不把这一新配方称为原FMT。它保留方向、复系数相位及各线之间的对应关系；六频截断仍有信息损失，不宣称任意流场无损或任意时变观察者客观。冻结编码器无可训练参数，仍使用`token -> 可训练神经网络 -> 查询轨迹`。

另设`vector_affine`：由同一231维token补零高频、逆傅里叶恢复31个增量，累加并恢复初始cross，随后使用冻结仿射查询/组合。它是无训练的压缩重建对照，不是神经网络臂，也不以真实隐藏query作为重建输入。
