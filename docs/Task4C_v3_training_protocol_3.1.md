## 仅改变读取与缓存

冻结 `Task4C_FixedDataset_2_1.py`、原编码、网络、优化器/选轮训练循环不修改。新增 `FMT_Utils/Task4C_V3Training_3_1.py`：

- 原始曲线、播种点、邻居表用 CPU 内存映射，按批索引。训练每轮仍遍历全部训练行，没有抽取小训练集。
- FMT 特征按旧批128计算，保存 float32 主机缓存，仅当前批送GPU；p35保留原 NumPy float64 总体均值/标准差，c156保留原逐批累计标准化。训练循环仍是 `Task4C_FPSAugmentSearch_1_1.train`。
- 三基线按批执行原 CPU 曲线簇归一化，仍为27槽、7/17有效曲线，与旧导出逐值一致。复用各家族原训练函数，仅重绑数据加载、取批与预测接口。
- Conv3D 即时执行原 `bundle_voxels`，保留原 float16→float32 往返；与原稀疏缓存重建逐值核对。省去重复展开完整曲线簇和全量体素缓存；模型及输入定义不变。编码的耗时包含在本版基线训练计时中，与原缓存版耗时不能直接比较。
- 权重仍仅在训练内存中选最佳轮，不写模型文件；保留特征、预测、选轮、运行与身份记录。

本地测试覆盖真实旧导出函数、随机重复/乱序取批、主机特征读取、原p35标准化逐值相同、十组单种子与一致样本行数。每组 GPU 预检使用真实训练样本，对照原输入、跨批FMT编码、128批反向、损失下降、参数量与显存；预检成绩不是正式测试F1。
