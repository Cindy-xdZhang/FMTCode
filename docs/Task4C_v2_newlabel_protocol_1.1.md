# v2_newlabel_rule：最短曲线多数标签

科学版本 `mainExp_Task4C_V2NewLabel_1.1`，数据集目录 `outputs/v2_newlabel_rule`。用户2026-09-20要求保留旧v2，另建新数据集，改用最短曲线的多数点GT标签，并尽量使正:负为1:2。本轮只构建数据，不恢复模型训练。

## 标签

每个样本仍有三种长度曲线。对保存的最短曲线（Channel单向0.07，TBL单向3.5）的32个等弧长采样点，逐点查询原人工标注网格单元的真实归属。任意非负实例编号都算hairpin，编号0有效；包围盒不代替标注单元。至少17点属于hairpin则label=1，否则为0；恰好16点为负。三种长度共用该标签。

保存32点各自的GT实例编号、命中数与比例，允许逐样本复核。原播种点的GT归属仍存gt_owner，旧标签另存seed_label，仅作诊断，不作为训练标签。实例归属仍由播种点依照原v2规则确定；曲线的新二分类标签不改变实例归属。

## 其余规则

沿用v2 r3配置：每场初始池2,000,000点、Poisson目标200,000点；Channel/TBL各一半；step1阈值与oyf>0、积分器、步长、三种长度、出域放宽、32点采样、三条全有效才保留、清洗不补采，全部不变。原始初始池仍在step1候选区内按物理体积均匀产生。原有数据和日志不覆盖、不删除。

具体实例→折映射复用冻结v2 r3。四个训练折全部用于训练，测试折0；不另建验证集。若后续用户要求训练，按其授权允许测试折指导早停，并明确记录，不用测试标签作梯度更新。

## 类别采样

先对初始池做最短曲线积分并判断曲线标签，再在同一个初始点池上按类别配额执行Poisson采样，正负点之间也必须遵守同一个最小间距。不得用播种点GT标签代理新类别。采用已验证的3.2全局类别配额Poisson实现；半径搜索仍用v2的算法。

最短曲线无效的提议不能成为最终样本，只在Poisson阶段计入非正配额，最终仍按原规则删除；其损失包含在试构建的类别保留率内。所有发布的样本标签均由真实有效最短曲线直接计算，原有三长度清洗门槛不放宽。预先最短积分与最终三长度积分的最短曲线命中数必须完全一致，否则停止构建并调查。

先按原v2试构建规模（每场200,000提议→1,000目标）使用正类配额1/3，测清洗后各类保留率s_pos/s_neg，再将正式正类配额设为`p=0.5*s_neg/(s_pos+0.5*s_neg)`。目标是清洗后每场正:负约1:2，记录相对目标误差是否≤5%；不强行改变标签、复制点或追加提议池来凑比例。若固定初始池的正类数不足配额，报告不足并停止，不暗改样本规模。各折仍以实例划分，不强行修改每折比例。

## 核验与执行

新增代码：`FMT_Utils/Task4C_V2NewLabel_1_1.py`、`experiments/Task4C_V2NewLabel_1_1.py`。流程：输入哈希与测试→两场试构建及核验→保留率校准→两场正式构建→全量独立核验。全部CPU，每作业4核；两流场可并行。只用原有一套数据构建随机数，无模型拟合。
