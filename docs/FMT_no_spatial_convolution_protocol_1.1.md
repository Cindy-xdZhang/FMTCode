# FMT 禁止空间卷积：项目硬性协议 1.1

生效日期：2026-09-17。用户明确要求删除所有含卷积的FMT方案，并禁止FMT任意探索使用空间卷积。本条优先于所有历史任务、搜索配置、冻结方案和旧推进授权。维护版本为 `Verify_FMTNoConvolution_1.1`；这次不新增训练、不改变旧实验数值。

## 必须遵守的规则

1. FMT的完整预测路径不得使用空间卷积。检查范围包括特征编码器、原始坐标分支、冻结预训练骨干、融合模块、预测头、重建器及后处理网络，不能只检查傅里叶分支。
2. 本次同时撤销曾引发混淆的沿轨迹采样轴一维卷积方案。FMT路径中禁止 `Conv1d/Conv2d/Conv3d`、相应转置卷积、函数式卷积及自定义等价卷积实现；不得以“时间卷积”“冻结Raw”“仅1×1投影”等称呼绕过规则。
3. 固定傅里叶变换、全连接多层感知机（MLP）、归一化、激活、均值/最大值统计不属于本次禁止的空间卷积。保持其原有数学定义，不能通过改名保留滑动卷积。
4. 独立、明确标名的非FMT卷积对照不是FMT方案；其成绩不得并入FMT名下，网络、预测和参数必须分开。已有这类对照作为历史证据保留，本次不启动它们。
5. 任意新的FMT版本提交训练前，必须保存完整网络结构、所有子模块类型及参数数；递归检查卷积模块，并检查函数式/自定义算子。调用 `assert_no_fmt_convolution`。发现卷积立即失败；没有忽略标记或自动豁免。只有用户后续明确修订本协议才能解除。
6. 方法命名必须同时说明固定表示与完整下游网络。不得将含原始轨迹网络的系统简写为“FMT＋MLP”。特征维数不代表整套模型结构。

## 结论纠正与证据边界

此前把Task3/5的p35/h0等完整系统简称为FMT，可能让人理解为“傅里叶特征＋全连接分类器” → 当前明确为“原始轨迹卷积骨干＋傅里叶辅助分支”，按用户裁定撤销 → 原因是完整预测中确有三层Conv1d → 原错误在于未清楚区分特征配方与完整网络，不能将整体成绩归因于傅里叶或纯MLP。

旧Task3/5主表、FMT残差搜索和二维FMT卷积超分辨结果不得作为当前FMT方法、主表、附录性能或“最佳FMT”的证据。历史预测、日志、配置和原科学提交不篡改、不伪装成无卷积复现；仅保留为撤销记录。旧主表的完整快照见 `docs/archive/retired_fmt_convolution_20260917/`。独立无卷积结果不随名称相同而被撤销。
