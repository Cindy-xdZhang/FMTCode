# Task3＋Task6 联合训练与任务专用门控，1.1

实验：`Verify_Task36_MultiGate_1.1`，2026-09-12。用户提出让原 FMT 频域分支和几何分支共同处理分类与重建，让不同任务学习不同门控。该版本建立独立的联合任务实验，不修改原 Task3、Task5、Task6 的方法、数据或历史结果。

## 1. 研究问题

单任务重建损失只奖励能降低坐标误差的表示。原 FMT 在分类中的既有优势不会自动成为重建网络的训练目标。因此，本次让分类目标与重建目标同时反向传播，并为每个任务提供单独的门控。

这是可检验的假设，不保证联合训练一定改善重建，也不预设分类必须选 FMT、重建必须选几何。参考 [Ma 等，2018，Modeling Task Relationships in Multi-task Learning with Multi-gate Mixture-of-Experts](https://research.google/pubs/modeling-task-relationships-in-multi-task-learning-with-multi-gate-mixture-of-experts/) 的共享专家、各任务独立门控思想。本项目的两个专家输入不同、目标为物理分类与轨迹重建，属于该思想的具体改造，不声称复现原论文的实验。

本轮几何分支采用已有验证集支持的全连接结构；不扩大 Point-NN 搜索。原 FMT 固定为 MoE 1.1 的 161 维配方，完整带符号 DFT、估算 IVD 的 aivd 配方均不混入。

## 2. 数据与目标

每个网络只训练一个流场。九流场、每流场 3072 个 primitive、七条路径线各 32 点、18 个训练尺度与 9 个未见尺度，全部继续使用冻结 3.1 源数据、4.1 子集和 MoE 1.1 的相同索引。开发种子 94110，最终 94111、94112、94113。原几何归一化、时间分块和完整路径线保持；Cylinder 起始时刻 7.5–12，其他流场原时段 10%–80%。

同一 primitive 提供两个目标：

- Task3 型分类目标：中心种子在原始物理位置和起始时刻的 IVD 是否大于等于同一时刻全空间 IVD 的第 95 百分位。IVD 是涡量向量减去全空间平均涡量后取模。使用已有 `compute_ivd_reference_3d` 和原空间插值算子；p95 来自整个加载空间网格，不来自抽样的 3072 个 primitive。
- Task6 目标：重建同一 primitive 的完整七条路径线，沿用原坐标误差单位与固定初始十字播种点。

Task6 缓存中的 `origin`、`seed_time`、`source_start`、`primitive_id` 和子集 `source_indices` 足以补算标签，不需要重新采样或积分。读取相同源文件及原 stride（最大空间维度 96），验证源文件大小、mtime、数据 manifest 与配置 SHA256；源速度出现缺失或标签仅有单类则明确失败，不用补零或改变采样制造标签。

分类标签、真实 IVD、p95 阈值、原物理位置、原时间、primitive ID 均不传入网络，只用归一化后的七线几何及其 FMT 特征。分类损失采用原种子标签，不由模型当前重建轨迹重新定义标签。不同尺度分类的未见尺度评测属于 Task5 式扩展，不能直接与旧固定尺度 Task3 主表数值比较。

训练和验证标签先生成；测试与未见尺度标签只在开发阶段结束并冻结 selection 后生成。源时间块不在两个任务间交叉使用；同一个样本不能在 Task3 中属于 train、在 Task6 中属于 test。测试是已使用过的重建 benchmark，并非新时间确认集。

重建目标依然由轨迹本身给出，但共享编码器额外得到 IVD 分类监督。因此整个模型属于**有监督分类＋自监督重建的联合训练**，不能继续称为纯自监督 Task6 方法。

## 3. 模型

共享专家输入与几何解码器沿用 `FMT_Utils/Task6FMTGeometryMoE_3D.py` 的全连接配置：

1. 专家 A：冻结 161 维原 FMT，补零至 651 维作容量匹配，训练集标准化，可训练全连接编码至 192 维 `z_A`。
2. 专家 B：651 个非初始原几何坐标，训练集标准化，相同宽 512、3 块全连接编码至 192 维 `z_B`。
3. 分类门控 `g_3` 和重建门控 `g_6`：各自读取 `[z_A,z_B]`，独立的 LayerNorm、128 宽全连接、GELU、2 维 softmax，输出输入相关的一对权重。两个门控从相同的 0.5/0.5 开始，无人工专家偏好。
4. `z_3 = g_3A z_A + g_3B z_B`，交给 256 宽全连接分类头，输出涡类别概率。
5. `z_6 = g_6A z_A + g_6B z_B`，交给宽 768、4 个残差块的几何解码器，输出后 31 个时刻、651 个坐标，再补回固定初始点。

任务身份由使用哪个门控和输出头表示，不把涡/非涡真实类别输入门控。专家参数在两个任务间共享，两个任务都可以通过各自的门控更新两个专家。主方法中不存在“某分支只能获得某任务梯度”的硬限制。

每个输出头接收 192 维 task-specific token；若要把同一 primitive 预存后再服务两个任务，共享专家对 `[z_A,z_B]` 总共 384 维。不能把这一对宣称为可同时服务两任务的单一 192 维通用 token。输出头没有原几何或原 FMT 的旁路，没有逆 DFT、PCA 或标签输入。

## 4. 联合损失与训练

用训练集中正类比例 `p` 定义分类样本权重：正类 `1/(2p)`，负类 `1/(2(1-p))`。对加权二分类交叉熵取样本平均并除以 `log(2)`，得到 `L_3`；恒为 0.5 的预测在训练集上对应 `L_3=1`。验证/测试不重估该权重。

令 `S²` 为训练集中全部非初始三维点相对训练集平均几何的平均平方距离。重建损失 `L_6 = mean(||x_hat-x||²)/S²`，初始输出训练集平均几何时训练损失为 1。两个任务的默认总损失为 `L=L_3+L_6`，只用训练集决定归一化；不使用测试集调损失权重。

不沿用 MoE 1.1 早期对 A、B 分别施加重建误差的辅助项：本轮问题正是允许两个专家通过不同任务产生分工。没有强制相等的门控负载约束，也没有强制两个任务使用相反专家的损失。硬分工作为独立对照。

所有新方法均固定学习率 0.0003、AdamW 权重衰减 0.001、dropout 0.1、72000 次更新、批大小 128、前 3000 次预热、余弦调度、梯度裁剪 1。每 3000 次读取完整验证集，保存 RAM 内最优状态。联合方法按验证 `L_3+L_6` 选择同一个 checkpoint，不能分别挑两任务最优 epoch 后拼成一行；单任务对照按自身验证损失选择。

确定 checkpoint 后，分类概率阈值只由验证 F1 选择。主分类指标为 Average Precision（AP，精确率–召回率曲线的阶梯积分，越大越好），另列 F1 和 AUROC。主重建指标为 `sqrt(sum XYZ error²/(N*7*31))`，越小越好，单位为邻居半径 r。不得把分类与重建两个测试指标相加后掩盖一方退步；分别报告两任务和计算代价。

## 5. 七组固定对照

| 代码标识 | 训练内容 | 回答的问题 |
|---|---|---|
| joint_task_gates | FMT A＋几何 B，两个独立门控，共同训练分类与重建 | 主方法：是否出现有用的任务分工 |
| joint_shared_gate | 相同两个专家，两个任务使用同一个门控 | 独立门控是否必要 |
| joint_raw_task_gates | A 改成原几何全连接专家，B 不变，两个独立门控 | 相同参数量下，FMT 本身是否提供收益 |
| joint_fixed_routes | 分类固定只走 A，重建固定只走 B | 学习门控是否优于预先指定专家 |
| joint_geometry_only | 仅几何 B，接分类与重建头，联合训练 | 多任务监督是否已足以解释变化 |
| single_task3 | 相同 FMT/几何双专家和分类门控，只训练分类损失 | 联合训练是否改善或损害分类 |
| single_task6 | 相同 FMT/几何双专家和重建门控，只训练重建损失 | 联合训练是否改善或损害重建 |

容量控制保留相同已分配参数：joint_task_gates 与 joint_raw_task_gates 参数量、初始化完全相同，区别为 A 的输入。shared/fixed/single 对照会保留不参与计算或梯度更新的模块，因此报告分配参数不能误作有效计算量完全一致。geometry_only 参数更少。所有单任务对照均重新训练；旧 Task6 MoE 1.1 和旧 Task3 主表继续作为历史证据，不能替代新联合数据的配对对照。

开发为九流场×七组，共 63 模型；不新增候选搜索，不从七个方法中选胜者后丢掉其余结果。只做数值检查：各重建方法验证误差须有限且 <3。通过后，测试标签生成、九流场×三种子×七组（189 模型）最终训练、逐流场审计和完整汇总自动依赖执行。任务单独不适用的指标记为空，不记为零。出现失败须保留；缺流场或种子不出完整均值。

## 6. 判断门控是否学到了分工

对相同验证 primitive 比较分类门控与重建门控的 FMT 权重，另测试强制仅 A、仅 B、错配 A 的影响。权重不是信息贡献百分比，强制路线的结果不是专家独立训练性能。

主方法至少应在 AP–重建误差两维上比较独立单任务、共享门控、双几何专家和固定分工。若只是分类更好、重建更差，属于任务权衡；若两个门控不同但两个指标没有优势，只能证明路由不同，不能证明路由有效。若联合 FMT 不优于联合双几何对照，不能把多任务学习的收益归因于 FMT。
